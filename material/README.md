### 关于「元素」属性（重要说明）

**两个活动的角色面板都不包含元素字段**，只有四项数值：**生命 / 攻击 / 防御 / 速度**（外加综合「战力」）。

官方规则原文提到「**元素攻击造成的伤害无视防御力**」，因此「元素」在本活动中体现为**技能的伤害类型**而非角色属性。
实际战斗日志中出现的伤害类型有：

| 伤害类型 | 结算方式 | 日志实例 |
|---|---|---|
| 普通伤害 | 攻击力 − 防御力 | 「寻梦者(18) 攻击 希娜狄雅(7) → 造成 **11** 点伤害」✅ 逐点吻合 |
| 技能多段伤害 | 按技能描述分段结算 | 「梦中的流星雨」3 波碎片 9×3 = **27** |
| **真实伤害 / 无视防御** | 独立于攻防差 | 「掣电一斩 …造成 25 点伤害（**含 8 点真实伤害**）」 |
| 百分比伤害 | 按目标当前生命比例 | 「梦中突袭 …造成敌方**当前生命 15%**，无视防御、护盾和减伤」 |

**结论**：若需「元素」字段，应以**技能描述的伤害类型**为准（如科拉莉的火焰、芽衣的雷/真实伤害、李素裳的流血），
而非寻找不存在的角色元素面板。
