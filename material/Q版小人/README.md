## 六、复现方式

采集脚本在仓库 `tmp/`（不进版本库）：

```bash
python tmp/mysearch.py "关键词" [页数]    # 米游社搜索
python tmp/mypost.py <post_id> [...]      # 下载帖子图片 + 联系表
python tmp/myemoji.py 5 6 11              # 下载官方表情 PNG/GIF
python tmp/build_qban.py                  # 表情 ↔ 高清图 dhash 匹配
python tmp/rebuild_all.py                 # ★一键重建全部（幂等，含隔离保护）
python tmp/sk_search.py                   # 樱/科斯魔 大范围搜索
python tmp/sk_pool.py                     # 候选池下载
python tmp/sk_build.py                    # 候选装配进目录
```
