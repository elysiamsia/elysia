## 四、重新生成 / 调参

```bash
python tools/spine_chibi/gen.py "material/Q版小人/格蕾修/直播Q版-01.png" \
       "material/Q版小人/格蕾修/Spine 骨骼动画模型/griseo" griseo
```

- 权重场（`fields`）、骨骼位置、每段动画的关键帧都在 `tools/spine_chibi/gen.py` 顶部/中部；
- 换角色只需改参数、换图，**动画名与骨骼名不要改**（前端契约）。

## 五、已知不足（等主人拍板再改进）

1. **原画是半身**（裁在大腿以上）→ 现在是半身战斗单位，没有腿；
2. **手臂没有拆分** → 攻击靠"前冲 + 身体挤压 + 头发惯性"，做不出抬手挥拳；
3. 要补这两点，需要：补全身原画 / 拆 10~14 个部件重新绑骨（每个角色工作量会大很多）。
