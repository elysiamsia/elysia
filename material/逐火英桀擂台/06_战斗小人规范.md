# 06 · 战斗小人规范（Spine 契约 v1）

> 2026-10-18 起草。给「赛博斗蛐蛐」战斗回放用的 Q版小人**统一规格**。
> 目的：13 位英桀共用**一套骨架 + 一套动画名**，前端只写一套驱动，回放事件直接映射动画。

---

## 一、坐标与朝向

| 项 | 约定 |
|---|---|
| 原点 | **脚底中心**（`root` 在 (0,0)） |
| 朝向 | 模型默认**朝右**（站左侧的选手） |
| 右侧选手 | 前端对整只做 `scaleX = -1` 镜像，**不要**另做一套朝左的模型 |
| 身高 | 生成时统一输出 **1000px 高**（图集），前端再按场景缩放 |
| 锚点 | 脚底贴地线（y=0），血条/名字由前端画 |

## 二、骨骼（11 根，名字固定）

```
root
└ hip                     髋（腰）
  ├ torso                 躯干（含胸）
  │ ├ head                头（旋转轴在脖子）
  │ │ ├ hairL / hairR     两侧头发（摆动）
  │ │ └ hairB             后发（摆动）
  │ ├ armL / armR         双臂（肩部）
  └ legL / legR           双腿
```

> 13 个角色全部用这套名字。技能特效、武器、光环一律**走独立 slot**（前端或美术后补），不要改骨骼名。

## 三、动画（8 段，名字与时长固定）

| 动画 | 时长 | 循环 | 用途 |
|---|---|---|---|
| `enter` | 0.90s | 否 | 入场（从上方落下 + 压扁回弹） |
| `idle` | 2.40s | **是** | 待机呼吸、头发摆、轻微点头 |
| `attack` | 0.62s | 否 | 普攻 A：蓄力 → 前冲 → 挥击 → 收势 |
| `attack2` | 0.62s | 否 | 普攻 B（反手），与 A 交替更耐看 |
| `hit` | 0.34s | 否 | 受击：后仰 + 后滑 + 红闪 |
| `cast` | 0.95s | 否 | 主动技能：蓄力 → 起跳 → 释放 |
| `stun` | 1.20s | 是 | 眩晕：左右摇晃 |
| `ko` | 0.80s | 否 | 倒地，**停在第 0.80s 姿势** |
| `win` | 0.80s | 否 | 胜利：跳一下 + 抬手 |

## 四、回放事件 → 动画（前端映射表）

`replays.json` 的 `events`（5 种 type）按下面映射：

| 事件 | 动作 |
|---|---|
| `hit`（普攻） | 攻击方播 `attack` / `attack2`（交替）；被击方播 `hit`，血条用 `target_hp` 更新 |
| `hit.crit = true` | 同上，前端额外加：会心白闪 + 震屏 + 大号伤害数字（不要指望模型动画） |
| `cast` | 播 `cast`，并弹出技能名 banner（`skill` 字段） |
| `stun` | 该角色播 `stun`，持续 1 回合 |
| `effect` | 纯前端特效（飘字/盾光/印记），模型不动 |
| HP 归零 | 播 `ko`，播完 **锁在最后一帧**（`track.timeScale = 0` 或 `setAnimation` 后不换） |
| 结算 | 胜者播 `win`；平局双方 `idle` |

## 五、前端驱动要点

1. 每个战斗单位一个 `spine.Skeleton` + `AnimationState`，**只占 track 0**；
2. 非循环动作用 `state.addAnimation(0, name, false, 0)` + 结束回调回 `idle`；
3. `ko` 用 `setAnimation(0,'ko',false)`，结束后把 `track.timeScale = 0` 冻结；
4. 左右镜像：`skeleton.scaleX = ±s`（注意 uv 不变，只是整体翻转）；
5. 缩放：`s = 目标身高 / 模型 bounds.h`，脚底对齐 `skeleton.y = -bounds.y * s + 地线`；
6. 白闪（受击/会心）：优先用前端叠一层白色剪影 / 整体 tint，不要写进 13 套动画；
7. 同屏只有 2 个模型 → **按场次懒加载**，别整包预载 13 个。

## 六、体积预算（手机端）

| 项 | 预算 |
|---|---|
| 单角色（png + atlas + json） | **≤ 800 KB** |
| 单场加载 | 2 个 = ≤ 1.6 MB |
| 13 个总量 | ≈ 8~10 MB（按需加载） |

当前样板（格蕾修）：png 712 KB + json 62 KB + atlas 0.2 KB = **777 KB**，达标。

## 七、已知限制（重要）

1. **原画只有半身**：`直播Q版-*.png` 是官方直播活动的立绘，**大多裁在大腿以上**（活动里人物坐在直播台后）。
   现在的样板因此是"半身战斗单位"。要做全身，需要：补全身原画 / 手绘下半身 / 或者接受"半身 + 底座"的擂台风格。
2. **没有手臂拆分**：当前是"单图网格 + 平滑权重"，手臂动作是整片形变带出来的，
   能做出**前冲、后仰、起跳、倒地、头发惯性**，但做不出"抬手挥拳"这种精细动作。
   要精细攻击 = 必须把原画拆成 10~14 个部件再绑（工作量大很多）。
3. 目前动画由脚本生成（`tools/spine_chibi/gen.py`），可以逐角色微调参数；
   用 Spine 编辑器（付费软件）可以再精修，但**不是必需**。

## 八、生成方式

```bash
python tools/spine_chibi/gen.py "material/Q版小人/<角色>/直播Q版-01.png" \
       "material/Q版小人/<角色>/Spine 骨骼动画模型/<name>" <name>
```

输出：`<name>.png / .atlas / .json`（Spine 4.1 JSON，可直接被 spine-webgl 读取）。
预览：`material/Q版小人/_spine_预览/viewer.html`（列表里会自动出现）。
对战演示：`material/Q版小人/_battle/battle.html`。
