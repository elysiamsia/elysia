## 一、金币经济

### 1.1 来源与去处

| 方向 | 项目 | 数量 |
|---|---|---|
| **产出** | 每日签到 | **600 金币** |
| | 连续签到加成 | 每日 **+100**，最多累计 **10 次** |
| | 满连签 **上限** | **1600 金币/天** |
| **消耗** | 押注 | 最低 **200**，**无上限**；猜错失去本金，猜中获得赔付 |
| **销毁** | 抽水 | **3%~8%**，按单场池规模递增（见 1.3） |
| | 兑换里程碑 | 累计金币兑换奖励（仿官方累计竞猜券兑换表） |
| **退还** | 平局 | **全额退还本金**（120 回合双方存活判平局） |

### 1.2 押注规则

- 单场**最低 200**、**无上限**（主人拍板）。
- **平局退本金**：不抽水、不赔付。
- **鲸鱼自我稀释**：池式结算下，单侧投注越集中，该侧赔率越低——投注者会稀释自己的赔付。极端例：某场池子原本 2,000:1,000、基础赔率 1.5；若某玩家在一侧追加 100,000，则该侧最终赔率变为 `103,000×0.95/102,000 ≈ 0.96`，**即使押中也会亏本**。
  → **系统提示规则**：当某侧投注占比超 90%、显示赔率低于 1.05 时，界面提示"该侧赔率已无获利空间"。

### 1.3 抽水档位（落在主人给定的 3%~8% 区间）

| 单场总池 | 抽水率 |
|---|---|
| < 5,000 | **3%**（鼓励小额场次参与） |
| 5,000 ~ 50,000 | **5%** |
| ≥ 50,000 | **8%**（抑制鲸鱼刷池） |

## 二、赔率体系

### 2.1 三层结构

| 层 | 公式 | 用途 |
|---|---|---|
| **基础赔率** | `clamp((1 − 5%) / p_win, 1.05, 19.0)` | 开盘标定、展示锚定；来源于 v6.7 胜率矩阵 |
| **动态池赔率（结算）** | 每 1 金币赔付 = `总池 × (1 − 抽水率) / 胜方池` | **实际结算**（pari-mutuel，严格按投注浮动） |
| **显示赔率** | `w × 池赔率 + (1 − w) × 基础赔率`，`w = min(1, 当前池 / 20000)` | 薄池时数字不剧烈跳动；池子做大了就交给市场 |

> **设计理由**：纯池式在薄池（开局几分钟）会出现赔率剧烈跳动与极端值；纯固定赔率又失去"按实际投注浮动"的博弈感。三层结构取两者之长——**结算严格跟池，展示做锚定平滑**。

### 2.2 基础赔率分布（78 组唯一对阵）

```
赔率区间 1.37 ~ 3.11
```

这是 v6.7 平衡成果的直接体现：因为对局胜率被压在 30%~70%，赔率自然落在 **1.4~2.9** 区间——**有热门冷门、无必输局**。

91 场赛程的逐场赔率见 [`data/schedule_odds.csv`](data/schedule_odds.csv)；78 组对阵的完整赔率见 [`data/rates.json`](data/rates.json)。

样例：

|---|---|---|---|
| #1 | 梅比乌斯 vs 帕朵菲莉丝 | 54.6% / 45.4% | 1.74 / 2.09 |
| #2 | 爱莉希雅 vs 华 | 66.9% / 33.1% | 1.42 / 2.86 |
| #3 | 千劫 vs 科斯魔 | 61.0% / 39.0% | 1.56 / 2.44 |

## 三、赛季模拟验证（`sim/economy.py`）

用**真实战斗引擎**打完整 91 场，让 5 种风格的模拟玩家下注：追热门 / 搏冷门 / 随机 / 价值派（只在期望值 >1.02 时下）/ 骑墙派（追高赔率）。

### 3.1 两种规模场景

| 指标 | 200 人局 | 20 人局 |
|---|---|---|
| 签到产出总计 | 6,460,000 | 646,000 |
| 投注总额（金币周转） | 19,548,600（**3.0 倍**） | 2,144,400（3.3 倍） |
| **实际抽水率** | **7.79%**（大池→高档） | **4.87%**（小池→中档） |
| 派彩总计 | 17,679,432 | 2,001,224 |
| 赛季末金币总量 | 4,937,632 | 541,624 |
| 人均金币 | 24,688 | 27,081 |
| **破产玩家** | **0 / 200** | **0 / 20** |
| **守恒校验** | **0**（精确） | **0**（精确） |

### 3.2 守恒校验（本模拟器的核心断言）

```
期末金币 + 销毁总额 − 签到产出 = 0
```

两种规模都**精确为 0**。含义：金币只会由签到产生、只会由抽水（及无人押中的池子）销毁，**不存在凭空生币或漏账**；池式结算的派彩总额恒等于 `池 × (1 − 抽水率)`，**系统永不亏空**。

### 3.3 结论

1. **永不亏空** ✅ 派彩恒等于池×(1−抽水)，抽水是真实销毁。
2. **不会集体破产** ✅ 最低押注 200 + 最高仓位 20% + 每日签到保底，两种规模下破产人数均为 0。
3. **抽水档位按池规模自适应** ✅ 小池 4.87%、大池 7.79%，始终在 3%~8% 区间内。
4. ⚠️ **金币是通胀型**：签到产出 646 万，抽水仅销毁 152 万 → 赛季末留存 **76%** 产出。原因很简单——**押注本身不销毁金币，只有抽水销毁**；而签到在持续产出。

## 四、赛季双榜（金币榜 + 眼力榜）

> **主人 2026-10-16 决定：不做兑换里程碑，赛季目标改为排行榜；先做金币持有榜，再按方案 C 增设眼力榜。**

### 4.1 金币榜规则

| 项 | 规则 |
|---|---|
| 榜单口径 | **金币持有量（余额）** |
| 周期 | **赛季榜**（23 天一个轮回结算）+ 每日 23:59 快照（日榜） |
| 范围 / 名额 | 全服 / 前 100 名 |
| **上榜资格** | 赛季内**至少参与 20 场押注** |
| 并列处理 | 金币 → 参与场次 → 押注命中率 → 昵称字典序 |
| 展示字段 | 名次 / 昵称 / 金币 / 参与场次 / 命中率 / 本赛季净收益 |

**为什么要设资格线**：抽水让押注成为**负和游戏**，所以"只签到、不下注"的挂机号会稳定拿到 3.23 万金币。不设资格线，认真玩的人反而被挂机号压住。

### 4.2 赛季模拟结果（200 名模拟玩家 · 真实战斗结算）

| 指标 | 结果 |
|---|---|
| 达标人数 | **160 / 200**（参与 ≥ 20 场） |
| 榜首 | **105,128 金币**（净收益 +72,828，命中率 62.2%） |
| 末位（达标者） | 9,485 金币 |
| 达标者人均 | 22,785 金币 |
| **纯挂机者（只签到不下注）** | 32,300 金币 → **若送上榜排第 51 名** |
| 分策略上榜 | 追热门 40 ／ 搏冷门 40 ／ 随机 40 ／ 骑墙 40 ／ **价值派 0** |

榜单文件：[`data/leaderboard.csv`](data/leaderboard.csv)

### 4.3 三个必须知道的结论

1. **资格线有效** ✅ 挂机号（3.23 万）只能排第 51 名，被认真玩的玩家压住；榜首是挂机号的 **3.3 倍**。
2. ⚠️ **金币榜上，靠的是运气而不是眼光**：前十全部是**随机派**与追热门派；"价值派"（只在期望值 >1.02 时下注）**一个人都没上榜**——赔率公平定价，几乎不存在正期望机会，价值派自然下不了几注、够不到门槛。**金币榜衡量的是"波动率"，不是"水平"** → 这正是增设**眼力榜**（见 4.4）的原因。
3. **押注整体是负和**：达标者人均 22,785，**低于**不押注的 32,300（抽水的必然结果）。

### 4.4 眼力榜（双榜并行，主人 2026-10-16 选定方案 C）

**金币榜**满足"攒钱变强"的爽感；**眼力榜**奖励真正会看对局的人。

#### 为什么不能直接排命中率（重要）

我最初设计的是"命中率榜"，模拟一跑就发现两个致命问题：

1. **命中率榜会与金币榜排出同一批人**——因为对局已被均衡到 40~60%、赔率又是公平定价（`(1−抽水)/胜率`），**"押得准"几乎全是运气**，赢得多的人自然也攒得多。
2. **原始命中率在小样本下毫无意义**——打 20 场蒙出 70% 很容易。

#### 最终指标：超额命中显著性 z

```
z = (实际命中数 − 期望命中数) / √Σp(1−p)
期望命中数 = 各场所押方向的"市场胜率"之和
```

含义：你押中的次数，**比市场给你的期望多多少**。

- 一路押 57% 的热门、赢 61% → z≈0.76（**只是跟着市场走**）
- 乱押 50% 的局、赢 62% → z≈2.44（**真正跑赢市场**）

#### 资格与规则

| 项 | 金币榜 | 眼力榜 |
|---|---|---|
| 指标 | 金币持有量 | 超额命中显著性 z |
| 资格 | 参与 ≥ 20 场 | **分出胜负 ≥ 45 场**（半个赛季） |
| 名额 | 前 100 | 前 100 |
| 并列 | 金币 → 场次 → 命中率 → 昵称 | z → 金币 → 昵称 |

#### 模拟结果（200 名玩家 · 真实战斗结算）

| 排名 | 玩家 | 实际命中 | 期望命中 | 超额 | z |
|---|---|---|---|---|---|
| 1 | random#197 | 62.2% | 49.6% | **+12.66pt** | **+2.44** |
| 2 | random#042 | 62.2% | 49.6% | +12.63pt | +2.43 |
| 3 | random#092 | 61.1% | 49.8% | +11.30pt | +2.18 |
| … | … | | | | |
| 9 | favorite#000 | 61.1% | **57.1%** | +3.96pt | **+0.76** |
| 10 | favorite#005 | 61.1% | 57.1% | +3.96pt | +0.76 |

**指标有效性验证** ✅：排名第 9 的玩家原始命中率 61.1%，与第 1 名（62.2%）几乎一样；但因为他是"一路押热门"，期望命中本来就该有 57.1%，超额只有 +3.96pt（z=0.76），**被正确降权**。而第 1 名在期望 49.6% 的局面上赢了 62.2%，是真正跑赢市场。

**没有虚高** ✅：模拟中的 200 名玩家**都没有真实预知能力**，因此 `|z|>1.96`（统计显著）的只有 5 人，而纯运气下本应有约 8 人——**指标没有把运气当成实力**。

榜单文件：[`data/leaderboard_accuracy.csv`](data/leaderboard_accuracy.csv)

### 4.5 通胀说明（榜单视角下不再致命）

取消兑换后，金币只由签到产出、只由抽水销毁，**总量必然通胀**（200 人局每天净增约 21 万）。但对"持有量排行榜"而言**不致命**——所有玩家同步通胀，**名次是相对值**。两点注意：
- 新玩家后期加入会有起跑线差距 → 建议**按赛季重置**（正好 23 天一周期）；
- 若将来要用金币兑换实物，需再引入销毁渠道。
