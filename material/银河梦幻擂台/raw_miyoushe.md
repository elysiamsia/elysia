## 1. 可用的米游社接口（【确认】，全部实测可用）

### 1.1 帖子搜索
```
GET https://api-takumi.miyoushe.com/post/wapi/searchPosts?keyword=<URL编码关键词>&page=1&size=20&gids=1
```
- 返回 `data.posts[]`，每项含 `post.subject / post.content（截断）/ post.images[] / post.post_id / stat`
- 分页参数 `page` 有效
- 实测关键词：`银河梦幻擂台`、`电子斗蛐蛐`、`梦幻擂台`、`火力全开`、`薇塔`、`面板` 等

### 1.2 话题帖子列表（**推荐，可拿到全量**）
```
GET https://bbs-api.miyoushe.com/post/wapi/getTopicPostList?topic_id=2491&page_size=20&sort_type=2[&last_id=<上页 last_id>]
```
- 话题 id **2491** = 「#火力全开！银河梦幻擂台！#」
- 使用 `last_id` 游标翻页
- **实测抓到 603 篇帖子**（page 0 ~ page 30，最后一页 `is_last=true`）

### 1.3 帖子全文
```
GET https://bbs-api.miyoushe.com/post/wapi/getPostFull?post_id=<id>&read=1
GET https://api-takumi.miyoushe.com/post/wapi/getPostFull?post_id=<id>     # 备用镜像
```
- 返回 `data.post.post.content`（HTML 或 JSON 字符串）、`structured_content`、`images[]`
- 注意：**高频请求会被限流，返回 `{"retcode":0,"data":{}}`（空 data）**；加 2~3 秒延时并交替两个域名可显著提高成功率

### 1.4 文章网页 URL 形式
```
https://www.miyoushe.com/bh3/article/<post_id>
```
（文章正文 JS 渲染，`web_fetch` 抓不到；必须走上面的 API）

### 1.5 图片直链
```
https://upload-bbs.miyoushe.com/upload/<年>/<月>/<日>/<uid>/<hash>_<num>.jpg|png
```
可直接 curl 下载（带 `Referer: https://www.miyoushe.com/`）。
