# B站原始材料（raw_bilibili）

> 采集方式：`curl` 直连 B站公开 API（`api.bilibili.com`），带 `User-Agent: Mozilla/5.0` 与 `Referer: https://www.bilibili.com/`。
> 注意：B站 web 接口对未登录/高频请求有**风控**（`code: -352`），评论只能拿到**热度排序第一页**。

## 1. 接口与可用性实测（【确认】）

| 接口 | 结果 |
|---|---|
| `GET https://api.bilibili.com/x/web-interface/view?bvid=<BV>` 或 `?aid=<av>` | ✅ 正常，返回标题/简介/分P(cid)/统计 |
| `GET https://api.bilibili.com/x/v2/reply?type=1&oid=<aid>&sort=2&ps=20&pn=1` | ⚠️ 只返回第 1 页（20 条）；`pn=2..6` 返回空 |
| `GET https://api.bilibili.com/x/v2/reply/main?type=1&oid=<aid>&mode=3&next=N` | ❌ `code=-352`（风控） |
| `GET https://api.bilibili.com/x/v2/reply/reply?type=1&oid=<aid>&root=<rpid>&ps=20&pn=1` | ❌ 返回空（风控） |
| `GET https://api.bilibili.com/x/v1/dm/list.so?oid=<cid>` | ⚠️ 可用，返回 deflate 压缩 XML；但**这些视频弹幕量极少（2~5 条）** |
| `GET https://api.bilibili.com/x/v2/dm/web/seg.so?type=1&oid=<cid>&segment_index=1` | ⚠️ 返回 340 字节（protobuf，本活动无有效内容） |
| `GET https://api.bilibili.com/x/web-interface/wbi/search/type?...` | ❌ 风控 |
| `platform_search(platform="bilibili")` | ✅ 可用（本次的主要视频发现手段） |
