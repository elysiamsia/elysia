# elysiad.top · 问题与解决方法总表

> **这份文件是什么**：把项目从 2026-09-15 到 2026-10-15 之间**实际踩过、并且被验证过**的问题，
> 按「症状 → 根因 → 解法 → 防复发的判据」四段式收成一张可检索的表。
> 素材全部来自 `docs/HANDOVER.md`（§5 / §6 / §10 为主）、`worker/README.md`、`tools/README.md`、
> `docs/theme-schema.md`，以及各轮 spec / plan —— **没有新增结论，只做提炼与归类**。
>
> **与 HANDOVER 的分工**：HANDOVER 是**时间线式**的交接文档（按轮次记录，越新越靠前）；
> 这份是**主题式**的问题库（按故障类型归类）。查「这一轮发生了什么」看 HANDOVER，
> 查「这类毛病以前怎么修的」看这里。
>
> **用它的方式**：遇到红 / 遇到静默不对 → 按症状在下面找分类 →
> 每题末尾的**判据**就是「怎么证明这条已经修好、且不会回来」。

## 一、上线与部署：**静默失败**最集中的一类

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| A1 | 文件明明在 `main` 上，线上却 404 | `static.yml` 的构建是**白名单拷贝**（只 `cp -r` `KEEP_DIRS`）。不在名单里的**连产物都进不去，而且不报错** —— 那道自检拦的是「不该进的路径」（`tools` / `docs` / `worker`…），**不拦「该进却没进的」** | 新目录必须写进 `KEEP_DIRS`。**唯一可靠的验法**：`curl -s -o /dev/null -w '%{http_code}\n' https://elysiad.top/<新页>/`。<br>**本地全绿 ≠ 线上存在**（2026-10-01 `mobius/` 在 main 上躺了 10 天，线上一直 404） |
| A2 | 「改了没生效」 | **两层缓存**：GitHub Pages 10 分钟 + Cloudflare 2 分钟 | 先怀疑缓存，再怀疑代码。见 `§7` 的线上缓存查询命令 |
| A3 | 只有 `main` 会部署 | `dev` 是自由折腾区 | 想在线上看效果，必须合进 `main`；`dev`「能打开」与线上「有没有这一页」是**两件事**（华那一轮、帕朵那一轮都栽过） |
| A4 | 新页「什么都对」，就是进不去 | **七个登记点各自静默失效**，没有一处会报错 | 见下面第六节（新页接入清单）—— 这是全项目最高频的漏项 |

## 二、后端 / Cloudflare

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| B1 | 开了橙云反而**更慢**（实测慢一倍多） | **默认不缓存 HTML** | 必须靠 Cache Rule |
| B2 | 刚通过的留言**两分钟后**才可见 | 加了 Cache Rule 后 API 响应被缓存 | API 响应必须 `no-store` —— 已在 `json()` 里统一处理 |
| B3 | 献花数字**悄悄停住不涨**，页面毫无报错 | KV 写额度 1000/天；每朵花写 2 次 ⇒ **全站约 500 朵/天**。超额后：读正常、`GET /count` 仍 200 但返回**冻结的旧数字**、`POST /flower` 500，前端**静默降级成本地计数** | 观察点：**11-11（她的生日）**当天献花数接近或超过 500 → 换 Durable Objects（方案见 `worker/README.md` §11.9 混合方案）。<br>⚠ **REST API（`wrangler kv`）路径不做额度检查但照样扣额度** —— 手动改数据也会吃掉额度且不提示 |
| B4 | 高流量时**丢花**（未修） | KV 是最终一致的，而 `POST /flower` 是「读出来 +1 再写回去」，并发时后写覆盖先写 | 与 B3 **同一个改动能一起解决**：换 Durable Objects（单线程、原子递增、按请求计费）。<br>判断：低流量看不出来，**正好在生日那天暴露** |
| B5 | 大陆访客永远看不到献花数字 | `*.workers.dev` 在大陆不可达（实测 HTTP 000、21 秒超时） | 生产 Worker **必须用自定义域名** |
| B6 | D1 建错区域 | 主区域创建时定死 | 只能用 `--location apac`，建错只能**删库重建** |

## 三、面向大陆访客：跨域与来源判定

这一类共同特征是：**降级是设计好的静默行为，症状是「数字不对」，不是报错。**

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| C1 | 同源之后**仍被 403**，只差一个字母 `s` | QQ 浏览器云加速把页面**降级成 http**，`Origin` 变成 `http://elysiad.top`，而白名单是精确字符串 `https://elysiad.top` | **只比主机名**（`new URL(origin).hostname`），且**必须精确比**（别用 `endsWith`，`elysiad.top.evil.com` 会漏进来） |
| C2 | 同一台手机同一网络：Edge 正常，QQ 浏览器 / 系统浏览器**页面能开但跨域请求被拦**，夸克连页面都打不开 | 接口跨域 | **接口必须与页面同源**：`/notes` 挂 `elysiad.top/notes*`；`flowers.elysiad.top` 只留给本地开发。<br>⚠ 加路由**不要**写成 `elysiad.top/*`，那会把整站静态页吞进 Worker |
| C3 | 献花接口不通时**不报错**，只把文案从「这里已收到 N 朵花」换成「你的花已送达 · 本机累计 N 朵」 | 静默降级 | **排查时先看文案，别看数字** |
| C4 | `http://elysiad.top/` 是通的（200，不跳转）—— 「始终使用 HTTPS」没开 | 有意保留 | ⚠ **别顺手开**：跨 origin 跳转时浏览器可能把 `Origin` 改成 `null`，会被同一道来源检查拦下。要开得先在手机上实测 |
| C5 | 环境判定写 `location.hostname === 'elysiad.top'` 会误判 | 浏览器云加速可能改写主机名 | 写成「**默认同源，只有本地开发才用远端地址**」 |
| C6 | C1~C5 修完不能只靠「手动试一次」 | 回归没守住 | `worker/test/smoke.mjs` 新增【12】共 12 项（献花 26 → **38** 项），并**验证过这 12 项在旧代码上会失败** —— 否则「测了等于没测」 |

## 四、验证工具自身的坑（快照类）

> 项目的安全网是「每一步都真跑」。但**工具本身也会说谎** —— 这一节全是工具骗人的实例。

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| D1 | 快照报「✅ 无差异」，而**属性类改动**（`aria-label` / `title` / `alt` / `href`）确实变了 | `snapshot.py` 采的是**计算样式**，**属性不在采样范围内** | 属性类改动走 `tools/check_aria_labels.py`。**改属性的改动，快照通过不算通过** |
| D2 | 快照对**减动**（`prefers-reduced-motion`）零差异 | 它不模拟媒体特性，跑的是默认无偏好路径 | 走 `tools/check_reduced_motion.py`（**双向**断言：减动下真的停了 + 正常下照旧还在） |
| D3 | 「页面无报错」断言全绿，**但文件整个缺了** | **资源 404 不写进 `Runtime`**，只在 CDP 的 `Log` 域冒一条 `source:network / level:error`。只判 `exceptionThrown` + `console.error` 的断言，缺文件一律通过 | `check_explore.py` 已收 `Log` 域。<br>⚠ 代价：**页面必须声明 favicon**，否则浏览器去要 `/favicon.ico` 拿 404 也算红 |
| D4 | 同一工作日内怎么复核都零差异，**跨过零点就报差异** | 页面有两处吃日期：「今日之语」按本地日期取句、`#bdayEgg` 每天换字 —— 它会**骗过一切当场自检** | `snapshot.py` 已把「现在几点」钉死在 `2026-09-16 12:00 UTC`。**改 `snapshot.py` 时别把 `SEED_DATE_JS` 弄丢** |
| D5 | 差分**少报差异**（实测 3 处被报成 1 处），而且**不报「快照缺失」** | 快照是 11 页 × 3 视口的慢循环，**跑完才落盘**；它还在跑的时候跑差分，读到的是**半份目录**。目录里还没有的页对它来说就是「不存在」 | 判据：**`len(PAGES) × 3` 文件数 + 后台输出末尾出现「快照存入 ……」+ 进程真的退出**。<br>⚠⚠ **重跑同一个 label 时文件数会骗你**（旧文件还在，没覆盖到的页看着也是齐的）⇒ 重跑只认「快照存入」那一行 + 进程退出 |
| D6 | 第 N 个实例改了什么，快照一律看不见 | `DUMP_JS` 用的是 **`document.querySelector`**（不是 `querySelectorAll`）—— 每个选择器**只采第一个匹配元素** | 对多实例类（`.hero-card` / `.quote-card` / `.timeline-node` / `.ending-star`）**「快照零差异」≠「没改」**。要验第 N 个得**另写探针**（`cdp.py … eval` 读它的属性 / 尺寸 / 文本）。<br>实例：给 `her-11` 补 `url`（首页第 11 张名片）→ 差分「零差异」 |
| D7 | 探索系统 / 下方区块 / 生日胶囊**改了，差分也看不见** | `SELECTORS` 那 39 个里**没有** `.explore-find` / `.bottom-*` / `.game-card` / `#bdayEgg` / `#bdayPanel` / `#blade*` —— 这三块在差分里**只看得到高度（`body`/`html`），看不到内容** | **别拿「快照零差异」去证明这三块没坏**，它们的正确性靠 `check_explore` / `check_aria_labels` 守 |
| D8 | 「换了图片源」这种改动，差分零差异 | `snapshot_diff.py` 比的是**计算样式**（`sel + prop` 的旧值/新值），**不比截图像素** | 这类改动靠 `check_postcard`（功能没坏）+ `check_page_health`（传输量掉了）来证。**别把「快照零差异」当成「视觉没变」** |
| D9 | 加了 `Math.random()` 调用之后，首页星屑"重洗"，差分报一堆 `.ending-star` 差异 | 种子流整体挪位 | 那些差异是**预期内的，不是回归**（明信片那一轮 16 处差异里 7 处是它） |
| D10 | 跑差分报出跟本轮无关的一堆差异 | **照抄了旧 label** 当参照点 | 参照点要**新建**（在 `git worktree add` 到动手前那个 commit 里跑），别照抄 `after-kosma` 那种跨两轮的 |
| D11 | 探测 `loading="lazy"` 的图片，下面全是 `0x0` | 图没加载 | 要把视口拉高 —— 那是**正常行为，不是回归** |
| D12 | 元素有入场动画时截到一片空白 | `.timeline-node` 是 `opacity:0` + IntersectionObserver 出 `.visible` | 滚过去要 `sleep` 一两秒再截 —— **那不是页面坏了** |

## 五、断言的坑：「看起来在守、其实守不住」

> 项目自己的定性：**「一条看起来在守、其实守不住的断言」比普通 bug 更值钱。**
> 标准动作是**变异测试**：故意把实现改成错的，看断言报不报红。**没做变异测试的断言，等于没写。**

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| E1 | 断言永远输出「相同」，测了等于没测 | 比较表达式是**恒真式** | 变异测试跑过才算 |
| E2 | 「字被二维码压住」——**两条像素判据全报绿** | 底部安全带只取 `x 0.15~0.72`（避开两朵水晶花），而二维码在 `x 0.767~0.957` —— **正好被排除在外** | 是 **Task 7 的「视觉核对」**（把 200 字真打进去截图）发现的。判据改读页面自己记的**只读**排版读数，且**竖版/横版两档都查** |
| E3 | 弹幕断言全绿，**手机上访客一个圆片都看不到** | 断言**只数 DOM 元素个数** —— 容器 `display:none`（焦点类没加上）照样绿 | **「渲染出来了」≠「看得见」**：判据要连 `display` + 高度一起判，并配一处变异证明有牙齿 |
| E4 | 「修完就好」——量出来**规则等于没写** | 第一版写成「整段一次问一个宽度」（`wrap(seg, 宽)`），整段都用全宽 | **规则写了不等于生效 —— 修完要再量一次那个读数** |
| E5 | 触摸断言**把 `pointerdown` 换成只吃鼠标的 `mousedown` 之后照样绿** | Chrome 会给 tap 补一套**兼容鼠标事件** | 它**不是**事件类型的守卫，是一条**端到端冒烟** —— **这句话必须写进断言的注释**，免得下一个人高估它 |
| E6 | 「在动」的判据挡不住只画一帧的实现 | 两采样挡不住（开始那一帧总会被画出来，`s1≠s2` 就成立）；三采样全等**也挡不住**（调试打印 `siglen 7174/9546/9546`，第一帧落在 s1 与 s2 之间） | 判据要盯**稳态**：**最后两次必须不同** |
| E7 | 断言**偶发**变红（时机赌运气） | 例：科斯魔原本写「按住 → 等『灯灭了』出现（最多 12 秒）」—— 光点赖在框里十几秒这一局就不结束 | **偶发的断言比没有断言更坏：它会教人忽略红灯。** 改成看 HUD 上可证伪的读数（如「风」），并**连跑三遍确认稳定** |
| E8 | 落点差 2px，**打空了，于是它在该红的时候是绿的** | 行为判据的落点 x 取成画布中线，而退出键左边缘恰好只偏 2px | **算术上「应该命中」不算数，变异测试跑过才算。差几个像素的落点，等于没有断言** |
| E9 | 只测了桌面，而**主战场是手机** | 「可发现物不压文字」原先只在默认视口（约 1256）跑：1256 下 0 个 ✓ / **375 下 4 个** ⚠。**坐标是锚点宽度的百分比 —— 换个宽度就落到别的内容上** | 断言扩成**两个视口都量**（`Emulation.setDeviceMetricsOverride`）。<br>扩了之后**把上一轮漏掉的一处也翻了出来**：mobius 在 375 下 `lab-06` 压着一个 emoji（那页**已经上线了**） |
| E10 | `cdp.py --window-size=375` **实际给出 492 宽** | Edge 有**最小窗口宽度** | 「量手机」只能靠 device metrics，**不能靠窗口尺寸**（`snapshot.py` 也是这么定义移动端的） |
| E11 | 同一个 (x,y) 探针报「干净」、断言报「压字」 | **探针环境和断言环境不一致**：探针用 `setDeviceMetricsOverride(1280)`，断言用 `--window-size`，两者 `innerWidth` 是 **1256 不是 1280**（滚动条占 24px），文字换行位置不同 | **探针要照抄断言的启动参数**，别自己另起一套环境 |
| E12 | 断言「靠时机侥幸在过」 | 开场 `<h1>` 是**打字机逐字写的**，**打完字会长高一截**，`sakura-01` 的坐标正好被它压住 | 断言**先等文字稳定再量**（`_wait_text_settles`），页面侧把落点挪开 |
| E13 | 变异测试「没做成」，断言**照样绿** | 撤掉 `#gameClose{position:absolute;...}` 想改回原位 —— 但那个 id 在文件里**有两条规则**，上一轮留下的那条还在生效 | **撤一个声明之前先 `grep`：同一件事有两处声明时，只改一处等于没改** |
| E14 | 变异测试「看见红了」，其实是**工具崩了** | 往断言里塞了个 JS 风格的 `/* */` 注释，工具当场崩 —— 退出码同样是 1、屏幕同样一片红 | **红也要看原因。** |
| E15 | 「全展开」是**假的** | 那些「展开」是**开关**，点三轮 `.click()` 看着字数从 3186 涨到 6073 就以为成了，其实 `给予刻印`（19 条）等三段还是折叠的（**漏 32%**） | **判据必须是「剩余 `[展开]` = 0」**（按可见性 `getBoundingClientRect().height > 0`），**不是「字数涨了」** |
| E16 | 用「行号范围」的脚本删代码块，**切歪了** | 多行字符串（`GAME_GEO`）的结束位置被算错，与另一段区间重叠；从后往前删时吃掉了 `main()` 开头和一个常量 | **删代码比写代码更该用「内容锚点」**，或删完用 `ast` 比对顶层名字 |
| E17 | 「写出来了」≠「生效了」 | 两处都栽过：① 断言只数 DOM 个数（见 E3）；② 「访客的字绕开二维码」第一版整段用全宽（见 E4） | **修完要再量一次那个读数，别拿「我写了」当证据** |

## 六、新页接入：七个登记点 + 必做清单

**症状的共同特征：⚠ 12 条里有 7 条「不会在页面上留下任何痕迹」**，而它们恰好就是
「线上到底有没有这一页」的那几条。华与帕朵两页都是 GitHub 网页 `Add files via upload`
上传的单个文件 —— **七个登记点全缺**。

| # | 漏了什么 | 后果 | 判据 |
|---|---|---|---|
| F1 | `static.yml` 的 `KEEP_DIRS` 白名单 | **不会上线**（线上 404），而 `dev` 上「明明能打开」 | 线上 `curl` |
| F2 | `sitemap.xml` | 搜索引擎找不到 | —— |
| F3 | `canonical` + JSON-LD | 与首页「谁才是权威页」说不清 | —— |
| F4 | `data/timeline-data.js` 的 `url` | 首页名片不亮小星、点不进去，**新页又成了孤岛** | 名片 url **12/12** |
| F5 | `check_aria_labels.py` 的 `EXPECTED` | 新页语录卡文案**没人守** | aria **13/13** |
| F6 | `snapshot.py` 的 `PAGES` | 快照**根本不拍这一页**，改动无从验证 | 快照清单 **14/14** |
| F7 | `check_reduced_motion.py` 的 `PAGES` | 新页减动**没人验**（该表是抽样，只覆盖 7 页） | 实测漏过 aponia / eden / su 三页 |
| F8 | `check_explore.py` 的 `EXPECTED_FINDS` | 探索度**声明数没人守** —— 少渲染一个也看不出来 | 探索登记 **6/6** |

## 七、取材与台词：**「逐字」这条纪律会反复咬人**

**结论一句话：材料包是「样本」，不是权威；brief 的候选值也只是「候选」，同样不是权威。
真正的库是官方档案馆。裁决顺序永远是 `spec > plan > brief 候选值`。**

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| G1 | 摘到的台词只有一点点 | 页面是 **SPA**，直接 `curl` 只拿得到 **6.6 KB 的壳**；**折叠段落里的台词在 `innerText` 里根本不存在** —— 不展开就摘会**漏掉 85%** | 四步：渲染 → **点开所有 `[展开]`**（要点**几轮**，会有新出现的展开，实测三轮后稳定）→ 按小标题切段 → 收「`角色：`」开头的行。<br>实例：樱 51 → **355**；科斯魔 57 → **186**（1 : 3.3）；格蕾修 23 → **112 + 17**（1 : 5）；苏 2337 字 → **19324 字 / 357 条**；凯文 2623 字 → **15408 字 / 250 条**（漏 6/7） |
| G2 | 引号 / 空格对不上 | **材料包把档案馆原文「整理」过了**：`「」`→`『』`、删掉中点前的半角空格 | **原文照录，一个字不改。改标点也是改台词**（例题：`tail` 那句、`「一起去『搞票大的』······！」` → 原文是 `一起去「搞票大的」 ······！`） |
| G3 | 掉了一个字（`griseo-06` 掉了开头的「嗯，」） | **不是材料包的账** —— 那一句材料包里根本没有（【日常展示】只到其一~其十，**缺其六、其八**）；是 **brief 的候选值转写时丢了一个字** | `Global Constraints` 的「原文照录」**优先于 brief 候选值** |
| G4 | 出处标错 | —— | **`src` 必须跟着抄准**（`官方档案馆 · 事件-<角色> · <子事件>`）—— **出处标错比不标更糟** |
| G5 | 台词**撞车**：玩家听她说刚说过的话 | 计划只查了**池子之间**，漏了另外两类 | **查重要查三类**：① 池子之间 ② **与页面正文**（正文不在「池子」里）③ **与页面自己的其它机制**（`heartLines` / 打字机 / 结尾引言**也用台词**）。<br>⚠ 查的时候**先把 `······` 与 `……` 两种省略号归一化**，否则同一句话会因标点不同被判「不重复」 |
| G6 | spec 与 plan 打架 | 计划是照**更早的初表**填的，而初表和 spec 打架 | **裁决顺序：spec > plan > brief 候选值**。（实例：spec 说「给予刻印那 17 条不混进 finds」，而计划 12 条里有 4 条取自它 → 现场按 spec 全换） |
| G7 | spec 自己没兑现 / 自相矛盾 | spec §4.2 落点表**逐行相加是 11、却写「合计 12」**；§3.5 说的「时间轴里有两套装甲版本节点」**实际没做** | **「计划与现场对不上要留痕」这条同样适用于 spec。** 两处**以落地为准**（12 条 / 9 节点口径），别照 spec 那半句改回去 |
| G8 | 材料包不是权威（`tail` 的根因） | 它按「需求下限摘 14 条」的思路做的（自己写着「已超 ≥10 的下限」），顺手把标点「整理」了一下 —— **它是给人读的「样本」，不是给机器核的「库」** | —— |

### 取材的两条通用手法

* **每个角色的子标题格式与说话人前缀都不一样** —— 别指望一个脚本打天下。
* **找「事件-XX」的 content id 去频道页**：`/bh3/wiki/channel/map/22/32`（往世乐土 → 事件）
  列着全部「事件-XX」与 id —— **别猜 id、也别指望搜索引擎**（它们只返回泛泛的百科结果）。
* 抓取脚本是**临时脚本，不进仓库**（项目纪律）。可复用的那份在 `tmp/fetch_archive.py`。

### 档案馆取词的真实路径（2026-10-15 澄清）

`content/<id>` 指 **`https://baike.mihoyo.com/bh3/wiki/content/<id>/detail`**（米游百科·圣芙蕾雅档案馆）。
⚠ **不是** wiki.biligame.com 的路径，**也不是** MediaWiki 的 pageid。
页面客户端渲染，**纯 `web_fetch` 只拿到壳标题**，必须用无头 Edge 读 `document.title` / `h1`。

### 抓取归档的四个坑（下一位照抄）

1. 那 34 个「展开」是**开关**；展开后 `<span class=obc-tmpl__expand-text>展开</span>`
   **仍在 DOM 里**（只是不可见）⇒ 判据要按**可见性**，不能按文本数。
2. **一轮只点一个、点完重新量**：一次取满坐标再逐个点，**内容长高会让后面的坐标失效**
   （实测那样点了 14 轮还剩 13 个；改成「点一个 → 重新量」后 34 次点完）。
3. 视口要开到 **30000 高**，否则元素在视口外、鼠标事件落在别处。
4. 判据是**「剩余 `[展开]` = 0」**（见 E15）。

## 八、游戏 / 小游戏：共享契约类

| # | 症状 | 根因 | 解法 / 判据 |
|---|---|---|---|
| H1 | 一页抄一份断言 = 给自己埋雷 | 到科斯魔为止已有三页各带小游戏，要守的东西有**三条完全通用** | 抽 `GAMES`（每页报上来的选择器 + **操作区**是哪个元素 + 有没有保护期）+ 四条通用断言：`check_game_runs` / `check_game_runs_under_reduced` / `check_game_fits_mobile` / `check_game_close_far_from_play`。<br>**「判定」不通用**（`check_sakura_judgment` / `check_kosma_judgment` 各页自己写） |
| H2 | **横屏放不下**（`fixed` 遮罩没滚动条，切掉的**够不着**） | 内容总高 > 横屏只有 360 | 加 `@media (max-height:520px) and (orientation:landscape)` 改**横排**（`display:grid` + `grid-template-areas`：画布一列、控制一列）。<br>⚠ **选择器要带 `.on`** —— 基线的 `#gameOverlay.on{display:flex}` **特异性更高**，只写 `#gameOverlay{display:grid}` 会被它压掉。<br>实例：mobius y −34、华格子 404px、帕朵画布 top −59 |
| H3 | **退出键贴着操作区**，手指落低一点点就退出 | 退出键原来在画布正下方（樱 55px / mobius 18px / 帕朵 74px 远不足） | 挪到**整个遮罩的右上角（屏幕角落）**：实测樱 201px、mobius 498px、华 182px、帕朵 106px、苏 191px、凯文 174px、阿波尼亚 174px。<br>⚠⚠ **「挪到面板右上角」这个直觉答案是错的** —— 面板的右上角离游戏区**一样近**。**量一下才知道要挪到「屏幕」的右上角。**<br>另加 **400ms 的「刚打开不许关」保护期**（挡双击 / 浏览器补发的延迟 click） |
| H4 | 量「离画布多远」看着很安全，**而真正的误触路径它一个字都没提** | 手机上真正的「操作区」**不一定是画布**：贪吃蛇是**滑动/方向盘**玩的 —— 手指落在画布上是滑动，**连点的是 `#dpad`**（「逃离实验室」就在 dpad 正下方 **18px**） | 断言要量**真正的**操作区。间距要求因此**分两档**：**连点处 ≥100px / 滑动面 ≥50px**（`CLOSE_FAR_MIN` / `CLOSE_SWIPE_MIN`）。<br>⚠ `swipe` 这个键要**显式给**（帕朵没有独立操作区 —— 篮子就是在画布上拖，不显式写就会被按 100px 量） |
| H5 | 「离画布 100px」**几何上做不到** | 矮屏上内容就要 524px，568 的屏只剩 44px 余量 | 判据**按「点它 / 在它上面拖」分两档**（见 H4），而不是硬套一个数 |
| H6 | 断言只管「在不在视口里」，**不管元素互相压** | 横屏横排之后，「逃离实验室」**压在标题行的「最高 0」上** | 用 `align-content:start` + `padding-top` 给它让出一行。**肉眼抓到一个断言测不到的** |
| H7 | **画布边框会把 `aspect-ratio` 带歪** | `aspect-ratio` 算的是**边框盒**，而断言量的是**内容盒** ⇒ 留 `border:1px` 就差 ~1px，360 视口当场判「拉扁」 | 边框改用 `box-shadow:0 0 0 1px`（不占布局）。<br>⚠ 苏那一页同款写法只是**侥幸**过（差 0.1px）—— 已一并改掉，免得哪天翻脸 |
| H8 | 「开局在动」抓到 **0.8 秒的死气** | 她原来第一件货要等 `gap ≈ 760ms` 才冒出来，那之前画布**完全静止**。而通用那条的采样窗口正好是 **0.9 秒**（s1/s2/s3 各隔 0.45s，要求后两次不同）⇒ 撞进空窗就红，**这条断言是「偶发」的** | **修页面，不改断言**：`start()` 里立刻 `spawnItem(18)` —— 开局就掉一件货。**这同时是个手感改进**。<br>💡 教训：**通用断言的时间窗是有长度的**。「画面迟早会动」≠「它现在在动」—— **开局第一秒必须是活的** |
| H9 | 遮罩断言**当场红** | 原来写成「点开始才建」遮罩 | 遮罩**必须在 `mount()` 的时候就建好**（默认 `aria-hidden="true"`、不带 `.on`）—— 断言 ① 第一件事就是看「它存不存在 + 是不是关着的」 |
| H10 | 游戏「**意义不明**」（第一版被需求方否掉） | 只有「冰 + 剑」的**皮**，跟这个人没关系 | **判据：写游戏之前先能用一句话说清「这个玩法 ＝ 他的哪句话」；说不清就别写。**<br>对照：樱的「一瞬」（刻印「刹那」＝**时机**）、科斯魔的「守灯」（「他要做的从来不是成为光，而是在夜里守住它」）—— **别人那个玩法本身就是那句话** |
| H11 | 「该开的地方只开了一半」 | 要一起打开的**有两处**：`<script src>` 行 ＋ `mount({ game: THEME.game })` | **单开脚本行 → 404；而 `check_explore.py` 收了 CDP 的 `Log` 域，404 算失败** |
| H12 | 过渡态产生**假红** | 建页那轮页面已接下方区块，但**游戏模块还不存在** —— 而「游戏卡文案 == 模块声明」那条**只在「没有游戏槽」时跳过**（判据是页面有没有传 `game`） | ✅ 正解是 **不传 `game`**（`ElysiaBottom.mount()` 不传参数）→ 槽不建、**断言正确地跳过**，页面是**诚实的过渡态**。<br>❌ 不要「传 `game` + 造一个 stub 模块」—— 骗过断言，但页面里多一份**假东西** |
| H13 | 游戏状态**外部读不到**（画在 canvas 上、脚本是 IIFE） | —— | **照玩家的方式看**：取画布上粉色像素的**质心**找到那枚花瓣，等它压到斩线上再出刀 ⇒ 断言**不依赖任何时间模型**。<br>⚠ 反例（阿波尼亚那轮）：想量「点在哪」**不能取每列第一个亮像素** —— 光晕（半径 26px）与目标环会给出**一串**命中（实测一列返回 5 个 y）。正解是**按亮度取核心像素、再按 40px 聚类取中心** |

## 十三、怎么用这份文档

1. **动手前**：按你要改的东西查对应分类（改部署 → 一；改接口 → 二 / 三；改视觉 → 九 / 十）。
2. **写断言时**：先读第五节（断言类）与第四节（工具盲区）—— 别写出第 E1~E17 种毛病。
3. **新页接入时**：第六节那张表**逐条过**（`check_explore.py <新页>` 先跑一遍）。
4. **遇到「零差异」**：先问「这个改动在**快照的采样范围**里吗」（D1 / D6 / D7 / D8）。
5. **遇到红**：按「真红 / 假红 / 偶发」分流 —— 假红（过渡态 H12、浮动元素 K8、时机 E7）要归因，
   **不要直接改断言**（K8 的做法是范本：先做归因实验，再决定动页面还是动口径）。

> 最后一句仍然照 HANDOVER §11：**该说「这个方案有问题」的时候直接说** ——
> 前面几轮里最有价值的产出，往往来自「我实测了一下，和你我原先的判断不一样」。
