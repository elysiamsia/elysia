# 崩坏3「竞猜擂台」类活动考证（调研日期 2026-10）

> 目录：`D:\claude-code\elysia-main`（本档为按需查证的外部活动调研，非仓库工作内容）
> 触发问题：用户问「银河梦幻擂台是什么活动」「之前版本有没有同类活动」。

## 一、当前活动：「火力全开！银河梦幻擂台！」

- 归属版本：崩坏3 **9.0「曙梦向明」**（其后为 9.1「时序照新」= 十周年版本，2026-09-25 上线，故 9.0 是十周年前置版本）。
- 档期：**2026-09-14 10:00 ~ 09-24 04:00**，参与等级 30 级以上（玩家实为网页活动）。
- 本质：**不是打怪，是竞猜押注**。选手两两对决，舰长依据选手「技能 + 属性」用「竞猜券」投票；押中按**返还倍率**返还更多券，押错则该注券清零。
- 赛程四阶段：小组赛 9/14–9/17 → 淘汰赛 9/18–9/19 → 半决赛 9/20 → 决赛 9/21。
- **战斗结算规则**（可被复刻成模拟器的部分）：回合制；按**出手速度**决定先后手；单次伤害 = **攻击力 − 防御力**，但**元素攻击无视防御**；双方触发被动/主动技能；先打空对方生命值者获胜。
- 奖励：竞猜券兑换**水晶、根源棱镜、远古意志、相转移镜面**。
- 彩蛋：09-14~09-23 每天 04:00 刷新一篇「娱乐新闻」，公告明确**纯娱乐、不影响结果**；参与竞猜与看新闻可解锁**隐藏成就**（成就**非** DOTA2 的「隐藏成就是宣传」梗）。
- 包装设定：「假期 + 一堆水电燃气账单里夹着一张比赛宣传单」。
- 已见对局：决赛 **寻梦者 vs 希娜狄雅**（官方宣发语：两位洛星神明之间的对决）；淘汰赛出现**布洛妮娅 vs 希儿**、**寻梦者 vs 游云**。
- **未证实（不可当事实引用）**：决赛胜负、最终赔率表。检索到的社区内容只有赛程复盘与造梗（如「布洛妮娅赔率 5.8 倍」「相信我，选芽衣」），无权威战报。

## 三、可复用的活动模板特征

1. 竞猜券投票 → 押中按倍率返还 / 押错清零。
2. 小组赛 → 淘汰赛 → 半决赛 → 决赛四阶段赛程。
3. 每日「娱乐新闻」（公告明说只是乐子，不影响结果）。
4. 参与即解锁隐藏成就；奖励池偏水晶 + 养成材料（根源棱镜 / 远古意志 / 相转移镜面）。
5. 网页端地址路径含 **`bet`** 标记，形如 `act.mihoyo.com/bh3/event/e<日期>bet-brjp02...` —— 可据此识别同模板活动。
6. 社区官方定位词：**「电子斗蛐蛐」**（米游社攻略原文口径：「娱乐性非常高的对战竞猜活动（电子斗蛐蛐）…竞猜各位角色的回合制对战结果，获取竞猜代币，完成竞猜成就」）。
7. 规则偏向「看起来可算」：回合制 + 速度定先后手 + 元素无视防御，正是催生「代码模拟胜率」攻略的原因。
8. 两次都压在**周年庆档期**，间隔约 10 个月；「周年限定竞猜」规律**样本仅两次**，不可断言。

## 四、易混淆 / 排除项

- 2019 年《崩坏3》亚太锦标赛「总决赛投票应援」（25 级可投）——为线下电竞赛事加油，**不是**角色虚构对战，不算同类。
- 「趣咔竞技赛」= 卡牌自动战斗；「飞向瓯夏」邀请赛 = 棋子消除；均**非**竞猜类。
- 2024 年八周年是否有同款：**未找到证据**，目前只确认 8.5 与 9.0 两次。
