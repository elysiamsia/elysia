## 二、一处格式约定（**不是差异**）

档案馆页面的小标题写 `落樱的追忆 · 其二`（`·` 两侧**有空格**），
本表与 `src` 一律写 `落樱的追忆·其二`（**无空格**）。

**这是引用格式的归一，不是改台词。** 理由是站内既有风格：
`mobius` 那批的 `src` 就是 `蛇主的追忆·其一`（无空格）。
如果为了跟页面标题一致而带上空格，全站 `src` 会出现两种写法。

> ⚠ 第一遍核对时我按原样字符串比，12 条全报「子事件对不上」——
> **那是我比对的锅，不是数据的锅**。归一化 `·` 两侧空白之后是 12/12。
> 记在这里：**核对脚本自己也会错，报「不一致」先怀疑脚本。**

## 六、抓取方法（后面每一位都要复用）

### 命令

```bash
# 抓取脚本在 %TEMP% 里（按纪律不进仓库），核心是用 cdp.py 渲染 + 点开折叠 + 提取
PYTHONIOENCODING=utf-8 python tools/cdp.py \
  "https://baike.mihoyo.com/bh3/wiki/content/881/detail" size 1280x900 sleep 9000 \
  eval "<点开所有「展开」的脚本>" sleep 6000 \
  eval "<提取 (子事件, 台词) 的脚本>"
```

提取逻辑（页面文本里**小标题与对话交替出现**）：

```
落樱的追忆 · 其二                    ← 子事件：匹配 /^[^：]{2,16} · 其[一二三四五六七八九十]+$/
樱：为了求生，我曾钻研诸武······      ← 台词：以「樱：」开头，去掉前三个字符
```

### ⚠ 两个必须知道的坑

1. **页面是 SPA** —— 直接 `curl` 只拿得到 **6.6 KB 的壳**，必须用无头浏览器渲染。
2. **大部分段落是折叠的** —— 折叠段落里的台词**在 `innerText` 里根本不存在**。
   实测：不展开 **51 条**，点开 39 个「展开」之后 **355 条**。
   **不展开就摘，会漏掉 85%。**
   ⚠ 点开要**点几轮**（会有新出现的展开），实测三轮之后稳定。

### 顺带记的

- 抓取脚本是**一次性的**（在 `%TEMP%`），但**每次换角色都要重写一遍提取部分**
  —— 子标题格式、说话人前缀（`樱：`）都会变。**别指望一个脚本打天下。**
- 每个角色的档案馆 URL 不同（樱是 `content/881`）。**要找下一个角色的 URL，
  从它的材料包 `text_materials.md` 的「出处链接」一节抄** —— 那批包都标了来源 URL。
- ⚠ 那 6 个**没有材料包**的页（kevin / aponia / eden / villv / kalpas / su）
  得自己去档案馆找对应条目 —— **材料包不在，URL 就得自己翻**。
