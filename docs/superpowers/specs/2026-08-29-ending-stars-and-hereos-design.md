- **C. 寄语双切换**：星空下的收束寄语可在两句间点击切换

## 结尾区设计（index.html `section-ending` 升级）

### 结构（三层从上到下）

1. **星光背景层**：保留现有 `ending-stars`（群星闪烁）作为底座。
2. **樱瓣→星光幻化**：粒子系统在滚动进入结尾时，把樱瓣渐次染成星屑白/紫（透明度+颜色渐变），
   与 A 的「从花到星」呼应。
3. **英桀名片星域**：`HEROS` 渲染十三张名片，环形/散点左右排布；每张上下错峰微飘
   （随机 `animation-delay`），hover 上浮+光强化，**点击展开**档案。
4. **寄语区**：星空下一句收束寄语，可点击在两句间切换。

### 英桀名片卡片样式
- 竖版小名片（约 150×210px），圆角 + 玻璃拟态（与现有卡片同语言 `--glass-bg`/`--glass-border`）
- 内容：位次罗马数字 + 刻印【】+ 中文名 + 外文名；顶部小徽章显示刻印
- 每英桀 `color` 字段定义主题色（名片边框/hover 光效用）

### 点击展开行为
- 点名片 → 名片放大/翻转成「档案卡」，显示：位次+刻印徽章 + 姓名 + **lore 档案文案**
  （文案来自官方截图提取，用户过目确认后写入；无 lore 时显示「档案待补」占位，不编造）
- **同时只展开一个**：展开新名片时收起上一张
- 点名片外部或再点名片 → 收起

### 寄语双切换
- 两句：`「带着我们的祝福，继续前进吧。」` / `「爱莉希雅永远都在这里，回应你的期待。」`
- 点击寄语文字区域切换，淡入淡出过渡
