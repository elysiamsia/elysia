# 四位英桀的小游戏 · 设计

> 起草 2026-10-15（按位铺开第五~八位：**阿波尼亚 Ⅲ / 伊甸 Ⅳ / 维尔薇 Ⅴ / 千劫 Ⅵ**）
> 依据：`docs/HANDOVER.md` §10.10（按位铺开的做法）、spec §4.5（游戏契约），
> 以及 **2026-10-15 被否掉的那版《碎冰》立下的判据**。

## 〇、先立判据（这份 spec 是照着它写的）

凯文的第一版《碎冰》（冰棱窜出来、拖着横扫斩碎）被需求方一句话否掉：「**游戏意义不明**」。
跟已有的玩法一比就看出差在哪 ——

| 页 | 玩法 | **它就是哪一句** |
|---|---|---|
| 梅比乌斯 | 贪吃蛇 · 实验体回收 | 她把一切都当实验素材 |
| 樱 | 一瞬（等时机出刀） | 刻印「**刹那**」；她一生只做一件事：在那一下出刀 |
| 科斯魔 | 守灯 | 「他要做的从来**不是成为光**，而是**在夜里守住它**」 |
| 格蕾修 | 上色 | 画家的世界是先有颜色才有形状 |
| 华 | 木人桩 | 打桩没有巧劲，只有一遍一遍 |
| 帕朵菲莉丝 | 接罐头 | 小卖部老板娘，来什么接什么 |
| 苏 | 数珠（记顺序） | 「觉者」——念珠就是他的母题，越数越深 |
| 凯文 | 五万年（烧自己的年岁换人类的时间） | 「**无论付出多少代价**，人类一定会战胜崩坏」 |

**判据（写游戏之前先答这一题）**：
> **这个玩法 ＝ 他的哪一句？**
> 答不出来、或者只能用「冰 / 剑 / 火 / 黄金」这种**名词**来答 —— 那就是只有皮，会被打回来。

⚠ 另一半判据来自上表：**八个玩法彼此不撞**。同一类机制（等时机 / 守 / 躲 / 涂 / 打桩 / 接 / 记 / 烧自己）
已经被占掉了，这一份设计要**避开它们**。

## 一、四位共同的硬要求（现成的契约，照抄，不重新发明）

| # | 要求 | 为什么 / 出处 |
|---|---|---|
| 1 | 挂 `window.ElysiaGames.<id> = { title, hint, mount(host), open }` | spec §4.5。`mount` 画出的卡里 `.game-card-title` / `.game-card-hint` 必须与 `title` / `hint` **逐字一致**（(26) 会比对） |
| 2 | **遮罩在 `mount()` 时就建好**（默认 `aria-hidden="true"`、不带 `.on`） | (23) 第一件事就是查「它存不存在 + 是不是关着的」。苏那一轮踩过（见 HANDOVER 2.3） |
| 3 | `CLOSE_GUARD_MS = 400`：刚打开那一小段点「收起」不算 | (25) 会验 |
| 4 | 画布边框**用 `box-shadow` 画，不要 `border`** | `aspect-ratio` 算的是**边框盒**、断言量的是**内容盒** ⇒ 留 1px 就判「拉扁」 |
| 5 | 画布属性比例固定（默认 340×420），CSS 只给 `width` + `height:auto` | (24) 会量「有没有被拉扁」 |
| 6 | **全程 rAF，不依赖 CSS 动画** | 减动偏好下也要能玩（(24) 的减动那一档） |
| 7 | 画面**从第一帧就在动**（飘雪 / 呼吸光 / 计时） | (23) 量「点开始后两次采样必须不同」 |
| 8 | 退出键固定挂**遮罩右上角**；操作面是**点触**的按 100px 量、是**拖动/按住**的按 50px 量 | (25)。口径在 `GAMES` 里用 `swipe` / `play` 声明 |
| 9 | 横屏（`max-height:520px and orientation:landscape`）改成左右两栏 + 画布按 vh 缩 | 遮罩是 `fixed`，没有滚动条，竖排塞不下 |
| 10 | 每个游戏都要**逐项量过 HUD**（不是只看「画面在动」） | 《五万年》那轮立的规矩（见 HANDOVER 2.3） |

**登记**（每个游戏接入时要动的地方）：
`tools/check_explore.py` 的 `GAMES` 加一条 + 该页 `THEME.game = { module: '<id>' }` + `ElysiaBottom.mount({ game: THEME.game })`。

## 二、玩法

### 2.1 阿波尼亚（Ⅲ · 戒律）——《戒律》

**她的那一句**：戒律不是愿望，是**她替所有人定下的结局**。
（⚠ 实施时从官方档案馆「事件-阿波尼亚」`content/1666` 取一句**逐字**台词作为卡上的注解，核准表照凯文/苏那两份写。）

**玩法一句话**：把「因」牵到「果」上 —— 而**线不许交叉**。

| 项 | 设计 |
|---|---|
| 操作 | 从一颗「因」（左侧的亮点）**按住拖**到一颗「果」（右侧候补点）上；松手即定。 |
| 规则 | ① **牵上就不能反悔**（不可撤销 —— 这就是「戒律」）；② **线不许相交**（规矩本身就是戒律）；③ 每牵一根，那一对人便「定下结局」（浮出一句短语）。 |
| 计分 | 每牵成一根 +1「定数」；牵出一条**与前线相交**的线 = 结束；无处可牵 = 结束。 |
| 难度 | 每过一关多一对因果（4 → 5 → 6…），候选点的位置更刁。 |
| 画面 | 深紫底 + 金色丝线（她那一页的配色）；丝线用二次贝塞尔**轻轻垂**（像真的线），悬停时线端发光。 |
| 为什么不是别的 | 不是等时机（樱）、不是守（科斯魔）、不是躲（梅比乌斯）—— 它是**空间约束下的连线**，全站没有第二种；而「不可反悔 + 不许交叉」两条规则**就是**「戒律」这两个字。 |
| 验收点 | 四条通用断言全绿；另外**量 HUD**：牵成一根 +1、牵出交叉线立刻结束、拖到空白处不算（不扣分）。 |
| 风险 | 「相交」判定要**几何**做（线段相交），别用 DOM 碰撞；候选点少的时候容易无解 ⇒ 生成时先验证存在一组不相交解（简单做法：先生成解、再把点随机平移）。 |

### 2.2 伊甸（Ⅳ · 黄金）——《和声》

**她的那一句**：美好的东西会走音、会散 —— 她要做的，是**把它调回该在的地方**。
（⚠ 实施时从档案馆「事件-伊甸」`content/909` 取一句逐字台词。）

**玩法一句话**：一条在飘的音准线，你拖着自己的声部**一直跟着它**。

| 项 | 设计 |
|---|---|
| 操作 | 画布上有一条**横向游走的「她的歌声」**（上下飘）；你按住拖动**控制自己的声部线**跟着它。 |
| 规则 | 两条线**贴得越近**，和声越亮；偏离超过阈值会「走音」（画面泛红、连击断）。歌会越唱越快、越飘。 |
| 计分 | 贴着时累积「和声」；一次贴满一段（例如 3 秒不脱离）算一个「乐句」+分。 |
| 结束 | 连续走音 N 次（或 45 秒计时结束）⇒ 报「留下多少和声」。 |
| 画面 | 暖金 + 唱片纹的同心圆；「她的歌声」线是金，「你的声部」线是月白，合上时叠成一条发亮的光带。 |
| 为什么不是别的 | 全站八个玩法里**没有一个需要「持续微调跟住一个会跑的目标」** —— 它既不是等时机，也不是记顺序，而是**手一直放在上面**。 |
| 验收点 | 四条通用断言 + 量 HUD：贴合时和声增长、脱开时停止增长且走音计数 +1、结束文案带出总分。 |
| 风险 | 拖动跟线在**触屏**上手指会挡住画面 ⇒ 声部线画在手指上方一段偏移处；阈值不能太严（要能在 320 宽上玩）。 |

### 2.3 维尔薇（Ⅴ · 螺旋）——《戏法》

**她的那一句**：你盯着的那只杯子，从来就不是你以为的那只。
（⚠ 实施时从档案馆「事件-维尔薇」`content/1667` 取一句逐字台词。她是「魔术师 / 工程师 / 怪盗」多重身份，母题是**螺旋**＝一层套一层。）

**玩法一句话**：三只杯子、一颗球 —— **你眼看着它换过位置**，然后指出球在哪。

| 项 | 设计 |
|---|---|
| 操作 | 先用 1.5 秒亮给你看球在哪只杯下 → 杯子**换位**（越来越快、越来越久）→ 你点你认定的那只。 |
| 规则 | 点中 +1「戏法」；点错结束。每过一轮加一只杯子（3 → 4 → 5…）并加快换位。 |
| 计分 | 连中的次数；最后一轮「她还会再骗你一次」—— 最高轮数记 `localStorage`。 |
| 画面 | 她那一页的紫色 + 舞台灯；杯子用她页面里已有的三种「面孔」配色（工程/魔术/怪盗），换位时带一点拖影。 |
| 为什么不是别的 | 不是记**顺序**（苏的数珠是「序列」），而是**盯住一个会动的东西**（连续追踪 + 记忆）；也不是躲/接。 |
| 验收点 | 四条通用断言 + 量 HUD：写脚本在「换位中」读出球坐标、点中 +1、点错结束。 |
| 风险 | 「点中」判定用**杯子矩形**不是像素；换位的运动轨迹要算得准（线性插值即可），别用 CSS 过渡（我们要 rAF）。 |

### 2.4 千劫（Ⅵ · 鏖灭）——《鏖灭》

**他的那一句**：烧的是别人，也是**自己**；什么时候收手，只有他自己知道。
（⚠ 实施时从档案馆「事件-千劫」`content/880` 取一句逐字台词。）

**玩法一句话**：每一拳都**烧掉自己一点**，打得越狠烧得越快 —— 而**收手**要你自己决定。

| 项 | 设计 |
|---|---|
| 操作 | 点画布 = 一拳。每拳让**敌人的火**小一分、让**自己的火**大一寸；连击越猛，倍率越高。 |
| 规则 | 你的火（HP）**只减不增**；倍率随连击上升。一个「收手」按钮：**按下即结算**（把当前分存下）。火尽 = 这一轮白打（只留最高分）。 |
| 计分 | 分数 = 打出的伤害总和；「收手」得的分进总账，火尽则这一局**归零**。 |
| 结束 | 火尽（或你收手之后重开）。 |
| 画面 | 黑红色调（他那一页的配色）+ 他页面上已有的那条**怒气条**语义：屏幕边缘随火势泛红、抖动幅度加大（**减动偏好下不抖，只变色**）。 |
| 为什么不是别的 | 全站没有**「风险取舍」**类玩法（push your luck）：不是等时机、不是记忆、不是接 —— 而是**你自己决定什么时候停**。 |
| 验收点 | 四条通用断言 + 量 HUD：连击时倍率上升、火只减不增、收手后分数入账、火尽后归零。 |
| 风险 | 抖动会碰 WCAG 2.3.1（他页面上已经有一处全屏抖动演出）⇒ **本游戏默认不抖**，只在火势超过 80% 时轻微位移，且减动下完全关掉。 |

## 三、实施顺序与批次

**一次一位，整页交付**（照樱 / 科斯魔 / 凯文 / 苏 的做法）：

| 批次 | 页 | 内容 |
|---|---|---|
| 1 | 阿波尼亚 | 游戏《戒律》+ 探索 12 条（`content/1666`）+ 登记 + 三项验收 |
| 2 | 伊甸 | 游戏《和声》+ 探索 12 条（`content/909`）+ 登记 + 三项验收 |
| 3 | 维尔薇 | 游戏《戏法》+ 探索 12 条（`content/1667`）+ 登记 + 三项验收 |
| 4 | 千劫 | 游戏《鏖灭》+ 探索 12 条（`content/880`）+ 登记 + 三项验收 |

> 建议从**阿波尼亚**开始：她的页面上「命运之丝」那个模块与《戒律》的视觉语言最接近，配色与 art 关键字能复用（`petal` 之外她会用到新关键字就登记）。

⚠ 四页里 **阿波尼亚 / 伊甸 / 维尔薇 有生日**（`data/bdays.js` 里已有：5/25、10/31、5/5）
⇒ 接入时要**同时补那 15 个 `--bday-*` 变量**（照各自 `:root` 取色），否则胶囊会串成首页爱莉希雅的粉紫（§4.1.2 / §5.2）。
千劫没有生日（页面与档案馆都没有）⇒ 照凯文/苏的做法：**组件照挂、胶囊不出现**。

## 四、不做的事（边界）

- **不写「只有皮」的玩法** —— 判据在前面，先答「这一句是什么」再动手；
- **不复用已有八个玩法的机制**（等时机 / 守 / 躲 / 涂 / 打桩 / 接 / 记顺序 / 烧自己的年岁）；
- **不加音效**（本站至今没有一处自动播放声音，加一个就会成为唯一）；
- **不做排行榜 / 分享**（那是另一个量级的活，且要 worker 支持）；
- **不为难度牺牲可玩性**：手机上（320 宽）玩不起来就重调，不「先上再看」。

## 五、附录：登记与新增清单

每个游戏接进 `tools/check_explore.py` 的 `GAMES` 时，按**操作面性质**选口径：

| 页 | overlay | canvas | close | 操作面 | `swipe` |
|---|---|---|---|---|---|
| 阿波尼亚 | `apoGameOverlay` | `#apoCanvas` | `#apoClose` | 拖线 = **拖动面** | ✅ `True`（50px） |
| 伊甸 | `edenGameOverlay` | `#edenCanvas` | `#edenClose` | 按住拖 = **拖动面** | ✅ `True`（50px） |
| 维尔薇 | `villvGameOverlay` | `#villvCanvas` | `#villvClose` | 点选 = **点触面** | ❌（100px） |
| 千劫 | `kalpasGameOverlay` | `#kalpasCanvas` | `#kalpasClose` | 连点 = **点触面** | ❌（100px） |

全部 `guard: True`（400ms 保护期）。

新增文件（每个游戏一个，与现有八个同构）：`assets/games/<id>.js`。
⚠ 卡上的 `title` / `hint` **只写在模块里**，`THEME.game` 只声明 `{ module: '<id>' }` —— 两边各写一份就会「同一件事两处维护」（§10.5 的教训）。

每页还要的探索资产（照凯文/苏那两份核准表）：
`docs/superpowers/plans/2026-10-<日>-<角色>-finds-table.md`（12 条逐字 + 出处 + 抓取说明）。
