## 〇、先立判据（这份 spec 是照着它写的）

凯文的第一版《碎冰》（冰棱窜出来、拖着横扫斩碎）被需求方一句话否掉：「**游戏意义不明**」。
跟已有的玩法一比就看出差在哪 ——

| 页 | 玩法 | **它就是哪一句** |
|---|---|---|
| 梅比乌斯 | 贪吃蛇 · 实验体回收 | 她把一切都当实验素材 |
| 樱 | 一瞬（等时机出刀） | 刻印「**刹那**」；她一生只做一件事：在那一下出刀 |
| 科斯魔 | 守灯 | 「他要做的从来**不是成为光**，而是**在夜里守住它**」 |
| 格蕾修 | 上色 | 画家的世界是先有颜色才有形状 |
| 华 | 木人桩 | 打桩没有巧劲，只有一遍一遍 |
| 帕朵菲莉丝 | 接罐头 | 小卖部老板娘，来什么接什么 |
| 苏 | 数珠（记顺序） | 「觉者」——念珠就是他的母题，越数越深 |
| 凯文 | 五万年（烧自己的年岁换人类的时间） | 「**无论付出多少代价**，人类一定会战胜崩坏」 |

**判据（写游戏之前先答这一题）**：
> **这个玩法 ＝ 他的哪一句？**
> 答不出来、或者只能用「冰 / 剑 / 火 / 黄金」这种**名词**来答 —— 那就是只有皮，会被打回来。

⚠ 另一半判据来自上表：**八个玩法彼此不撞**。同一类机制（等时机 / 守 / 躲 / 涂 / 打桩 / 接 / 记 / 烧自己）
已经被占掉了，这一份设计要**避开它们**。

> ⚠ **另有两处「手感家族」相近，别让它们长成同一款**（复核时逐条量过，不是硬冲突，是要守住差异）：
> · **伊甸《和声》↔ 凯文《五万年》**：都是「一条线撑着一整屏、松了就输」的持续张力。差异在**输入性质**
>   （凯文＝按住 / 松手二值；伊甸＝拖着**一路微调**）与**冷暖基调**（冰 vs 暖金）。
>   ⇒ 实现时别把伊甸的画面也做成「压迫感」，她那一款是**抒情**的。
> · **千劫《鏖灭》↔ 凯文《五万年》**：都是「只减不增的自耗资源」。差异在**有没有那个决定** ——
>   凯文没有收手的余地（只能按住直到烧完），千劫**整个游戏就是「什么时候停」**。
>   ⇒ 千劫的「收手」必须是画面与交互上**最重的那一下**，不许做成角落里一个小按钮。

## 一、四位共同的硬要求（现成的契约，照抄，不重新发明）

| # | 要求 | 为什么 / 出处 |
|---|---|---|
| 1 | 挂 `window.ElysiaGames.<id> = { title, hint, mount(host), open }` | spec §4.5。`mount` 画出的卡里 `.game-card-title` / `.game-card-hint` 必须与 `title` / `hint` **逐字一致**（(26) 会比对） |
| 2 | **遮罩在 `mount()` 时就建好**（默认 `aria-hidden="true"`、不带 `.on`） | (23) 第一件事就是查「它存不存在 + 是不是关着的」。苏那一轮踩过（见 HANDOVER 2.3） |
| 3 | `CLOSE_GUARD_MS = 400`：刚打开那一小段点「收起」不算 | (25) 会验 |
| 4 | 画布边框**用 `box-shadow` 画，不要 `border`** | `aspect-ratio` 算的是**边框盒**、断言量的是**内容盒** ⇒ 留 1px 就判「拉扁」 |
| 5 | 画布属性比例固定（默认 340×420），CSS 只给 `width` + `height:auto` | (24) 会量「有没有被拉扁」 |
| 6 | **全程 rAF，不依赖 CSS 动画** | 减动偏好下也要能玩（(24) 的减动那一档） |
| 7 | 画面**从第一帧就在动**（飘雪 / 呼吸光 / 计时） | (23) 量「点开始后两次采样必须不同」 |
| 8 | 退出键固定挂**遮罩右上角**；操作面是**点触**的按 100px 量、是**拖动/按住**的按 50px 量 | (25)。口径在 `GAMES` 里用 `swipe` / `play` 声明 |
| 9 | 横屏（`max-height:520px and orientation:landscape`）改成左右两栏 + 画布按 vh 缩 | 遮罩是 `fixed`，没有滚动条，竖排塞不下 |
| 10 | 每个游戏都要**逐项量过 HUD**（不是只看「画面在动」） | 《五万年》那轮立的规矩（见 HANDOVER 2.3） |
| **11** | **结局只说一件事**：一句人物语气的话 + 一个数字 + 「再来一次」键 —— 不是「你得了多少分」 | 《五万年》先例（HANDOVER 2.3）：「结局只报一件事：**你给人类留下了多少年**」。四款的结束语在各自小节的「数字与教学」里**已定稿**，照着写 |
| **12** | **每帧 `dt` 钳制**：`var dt = Math.min(0.05, (now - last) / 1000)` | `kevin.js:166` / `kosma.js:215` / `sakura.js:179` 三处同款写法。受众从 QQ / 微信内嵌浏览器进来，**切后台再回前台那一下**不钳 ⇒ 四款全是冤死：伊甸的计时会跳、千劫的火会跳、阿波尼亚的点会瞬移、维尔薇的杯子会传送 |
| **13** | **开局十秒自己会教**：第一关必须是「拉一下就会」的难度 | 维尔薇已写清（1.5s 亮牌 → 慢换）；另三款的教法见各自「数字与教学」。⚠ **不许把教学写在 `hint` 里就算数** —— 那是卡面文案，不是教学 |
| **14** | **游戏内按钮（除「收起」之外的第二个键）也要量间距**：离玩家操作面 ≥ **100px**（点触面口径），开局 **150ms** 内忽略 | 现有契约只管「收起」键。千劫新引入的「收手」是**第二个键** —— 连点时手指落偏一点就提前入账（不是扣分，是**毁掉一次决定**）。维尔薇若加「再来一次」按同一口径 |

**登记**（每个游戏接入时要动的地方）：
`tools/check_explore.py` 的 `GAMES` 加一条 + 该页 `THEME.game = { module: '<id>' }` + `ElysiaBottom.mount({ game: THEME.game })`。

## 二、玩法

### 2.1 阿波尼亚（Ⅲ · 戒律）——《戒律》

**她的那一句**：戒律不是愿望，是**她替所有人定下的结局**。
（⚠ 实施时从官方档案馆「事件-阿波尼亚」`content/1666` 取一句**逐字**台词作为卡上的注解，核准表照凯文/苏那两份写。
✅ **id 已核验**，见 §七。）

**玩法一句话**：把「因」牵到「果」上 —— 而**线不许交叉**。

| 项 | 设计 |
|---|---|
| 操作 | 从一颗「因」（左侧的亮点）**按住拖**到一颗「果」（右侧候补点）上；松手即定。**拖动中画预览线**（见风险②）。 |
| 规则 | ① **牵上就不能反悔**（不可撤销 —— 这就是「戒律」；⚠ **反悔的界线是「松手」**，松手之前不算）；② **线不许相交**（规矩本身就是戒律）；③ 每牵一根，那一对人便「定下结局」（浮出一句短语）。 |
| 计分 | 每牵成一根 +1「定数」；牵出一条**与前线相交**的线 = 结束；无处可牵 = 结束。 |
| 难度 | 每过一关多一对因果（**第一关 2 对** → 4 → 5 → 6 → **cap 6~7 对**），候选点的位置更刁。⚠ **不再往上加对**：6 对以后点与点的间距会小于触控尺寸，后期加的是「刁」不是「多」。 |
| 画面 | 深紫底 + **烛光金**丝线（用她页面现成的 `--candle:#e8c98a` / `--candle-deep:#c9a45c`，底色 `--bg-abyss:#08060e` / `--violet:#9d8fd0`）；丝线**画直**（见风险①），悬停 / 拖动时线端发光。 |
| 为什么不是别的 | 不是等时机（樱）、不是守（科斯魔）、不是躲（梅比乌斯）—— 它是**空间约束下的连线**，全站没有第二种；而「不可反悔 + 不许交叉」两条规则**就是**「戒律」这两个字。 |
| 验收点 | 四条通用断言全绿；另外**量 HUD**：牵成一根 +1、牵出交叉线立刻结束、拖到空白处不算（不扣分）；**另量三条新判据**：松手前预览线在「会相交」时变色、**判定与所见一致**（走直线 ⇒ 量丝线是直的；走采样 ⇒ 量判定用的是绘制的那同一组采样点）、第一关 2 对可通关。 |
| 风险 | ① **判定必须与所见一致**：原稿「二次贝塞尔垂线」＋「线段相交判定」是**自相矛盾的**（弦线相交 ≠ 视觉上垂线的相交）—— 玩家会被一条看不出相交的线判死，或放出一条看得见相交的线。**二选一**：**画直线**（「牵上＝拉直」，推荐，小画布上更清晰）或判定用与绘制**同一组采样点**逐段相交。② **相交不许是隐形的**：拖动中画预览线，**松手前**若会交叉就渲染成警示色（暖红，如 `#ff7a6b`，只在那一瞬出现）—— 不可反悔在松手之后才生效，张力还在，但玩家第一次死之前就学会了规则。③ 生成时先验证存在一组不相交解（先生成解、再把点随机平移）。 |

**数字与教学**（开工前按这组起步值实现，真机再调）：

- **教学**：第一关 **2 对**。一次成功的牵线就把两条规则都教会（松手即定 + 不许交叉）。
- **触控**：点的命中区 ≥ **32px**；点与点的间距 ≥ **24px**（6~7 对时的底线）。
- **失败归因**（玩家永远要知道自己为什么输）：交叉 ⇒ 高亮**那一条**新线并说「你牵出了一条交叉的线」；无解 ⇒ 「所有能牵的尽头都到了」。
- **结束语**（照第 11 条）：
  · 无解：「你替他们把结局都定好了。　　一共定下 **N** 个结局。」
  · 交叉：「有一根线，牵到了不该去的地方。　　你定下了 **N** 个结局。」

### 2.2 伊甸（Ⅳ · 黄金）——《和声》

**她的那一句**：美好的东西会走音、会散 —— 她要做的，是**把它调回该在的地方**。
（⚠ 实施时从档案馆「事件-伊甸」`content/909` 取一句逐字台词。✅ **id 已核验**，见 §七。）

**玩法一句话**：一条在飘的音准线，你拖着自己的声部**一直跟着它**。

| 项 | 设计 |
|---|---|
| 操作 | 画布上有一条**横向游走的「她的歌声」**（上下飘）；你按住拖动**控制自己的声部线**跟着它。⚠ **视觉偏移**：声部线画在手指**上方 ~40px**，但**输入映射到那条线上** —— 偏移**只是视觉的**，别把映射也偏了（否则手感永远调不对）。 |
| 规则 | 两条线**贴得越近**，和声越亮；偏离超过 **±30px（约画布高的 ±7%）** 且**持续 > 600ms** 才算一次「走音」（短滑、抖一下**原谅**，不计数）。歌会越唱越快、越飘，但**有上限**（见下）。 |
| 计分 | 贴着时累积「和声」；一次贴满 **3 秒**不脱离算一个「乐句」+分。 |
| 结束 | **45 秒歌尽**（＝她唱完了，是**正面**收尾，不是超时判负）或走音满 **5** 次 ⇒ 报「留下多少和声」。 |
| 画面 | 暖金 + 唱片纹的同心圆（用她页面的 `--gold:#ffd166` / `--gold-mist:#ffe9b8`，底 `--bg-abyss:#0a0608` / `--bg-wine:#241019`）；「她的歌声」线是金，「你的声部」线是月白，合上时叠成一条发亮的光带。⚠ 走音的反馈**别只靠变红**（色觉障碍）：同时把光带**亮度掉一档**，并让两条线**分开可见**。 |
| 为什么不是别的 | 全站八个玩法里**没有一个需要「持续微调跟住一个会跑的目标」** —— 它既不是等时机，也不是记顺序，而是**手一直放在上面**。与凯文的差别见 §〇 的「手感家族」。 |
| 验收点 | 四条通用断言 + 量 HUD：贴合时和声增长、脱开时停止增长且**持续 600ms 后**走音计数 +1、结束文案带出总分；**另量**：前 8 秒的起步速度（慢而近平）、45 秒走完是正面收尾。 |
| 风险 | 拖动跟线在**触屏**上手指会挡住画面 ⇒ 声部线画在手指上方一段偏移处（**仅视觉**，见「操作」）。阈值不能太严（要能在 320 宽上玩）：±30px 只是**起点**，真机按 320 宽调。 |

**数字与教学**（这一款是四款里**最难调**的，数字必须写死才有的调）：

- **教学（前 8 秒 = 她起个头）**：歌速 ≈ 一秒走完半个画布高、摆幅 < 10px。玩家在这 8 秒里学会「按住拖着跟」，且几乎不可能走音。
- **爬升有上限**：之后每 10 秒速度 +15%、摆幅最多 ×1.6，**cap 在人类的水平**（大约 3.5 秒一个来回）—— 越过这条线就不是「跟歌」是「抽奖」。
- **阈值**：贴合带 ±30px；脱离判定 **> 600ms**；走音满 **5** 次结束；「乐句」= 连续贴合 3 秒。
- **结束语**（照第 11 条）：
  · 歌尽：「你和上了她的歌。　　留下 **N** 段和声。」
  · 走音满：「有一段，你没能跟上。　　留下 **N** 段和声。」
- ⚠ **音效**：决定保留「四款都不配音」，但**理由要改正**（见 §四）；她这一款要不要用她页面上同款的振荡器和弦，属需求方拍板 —— 见 §五。

### 2.3 维尔薇（Ⅴ · 螺旋）——《戏法》

**她的那一句**：你盯着的那只杯子，从来就不是你以为的那只。
（⚠ 实施时从档案馆「事件-维尔薇」`content/1667` 取一句逐字台词。她是「魔术师 / 工程师 / 怪盗」多重身份，母题是**螺旋**＝一层套一层。
✅ **id 已核验**，见 §七。）

**玩法一句话**：三只杯子、一颗球 —— **你眼看着它换过位置**，然后指出球在哪。

| 项 | 设计 |
|---|---|
| 操作 | 先用 1.5 秒亮给你看球在哪只杯下 → 杯子**换位**（越来越快、越来越久，但有上限）→ 你点你认定的那只。 |
| 规则 | 点中 +1「戏法」；点错结束。每过一轮加一只杯子（**3 → 4 → 5，cap 5**）并加快换位（**有上限**）。**「球永远不撒谎」**（新增铁律）：换位是物理连续的，任何一轮都不假换、不瞬移、不在你看不见的时候偷换 —— **误导 ≠ 欺骗**（她页面上大魔术师的原话：「魔术的要诀，就是**误导**」）。 |
| 计分 | 连中的次数。**「她还会再骗你一次」落实为**：输的那一下**亮出球的真实位置**（＝她揭幕），不许只当一句台词。最高轮数记 `localStorage`（⚠ 四款的记录政策见 §五）。 |
| 难度 | 杯数 cap **5**（五杯时每只仍 ≥ **60px** 宽、命中区 ≥ **44px**）；**一次 burst ≤ 3 次换位**；**单次换位 ≥ 400ms**。分数来自**连续多轮**的 streak，不来自单轮速度 —— 越过人眼极限就不是「盯」是「赌」。 |
| 画面 | 舞台紫 + 灯（她页面 `--bg-stage:#2a1040` / `--accent:#ff6b9d`）；杯子用**她页面里真有的前三种人格配色**：指挥家 `#ffd166` / 大魔术师 `#ff6b9d` / 专家 `#4ecdc4`（⚠ 原稿写「工程 / 魔术 / 怪盗」—— 与页面人格名对不上，颜色是存在的）。换位带一点拖影，但**拖影只能是装饰**：不许糊到看不清杯子。 |
| 为什么不是别的 | 不是记**顺序**（苏的数珠是「序列」），而是**盯住一个会动的东西**（连续追踪 + 记忆）；也不是躲 / 接。 |
| 验收点 | 四条通用断言 + 量 HUD：写脚本在「换位中」读出球坐标、点中 +1、点错结束；**另量**：换位是插值连续（无瞬移）、输的那一刻球的位置被亮出来。 |
| 风险 | 「点中」判定用**杯子矩形**不是像素；换位的运动轨迹要算得准（线性插值即可），别用 CSS 过渡（我们要 rAF）。**另**：`localStorage` 要能承受「隐私模式 / 存储被禁」（`try/catch` 兜底，读不到就当没有记录）。 |

**数字与教学**：

- **教学（第一轮）**：3 只杯、1.5 秒亮牌、只换 **1 次**慢换。第一轮**必须**是「看一眼就知道」的难度。
- **爬升**：单次换位 900ms 起，每轮 −80ms，**降到 400ms 为止**；burst 1 → 2 → 3（**cap 3**）；杯数 3 → 4 → 5（**cap 5**）。
- **结束语**（照第 11 条，并且是揭幕那一刻的台词）：「球在另一只杯下。　　你看穿了 **N** 次。」

### 2.4 千劫（Ⅵ · 鏖灭）——《鏖灭》

**他的那一句**：烧的是别人，也是**自己**；什么时候收手，只有他自己知道。
（⚠ 实施时从档案馆「事件-千劫」`content/880` 取一句逐字台词。✅ **id 已核验**，见 §七。）

**玩法一句话**：每一拳都**烧掉自己一点**，打得越狠烧得越快 —— 而**收手**要你自己决定。

| 项 | 设计 |
|---|---|
| 操作 | 点画布 = 一拳。每拳让**敌人的火**小一分、让**自己的火**大一寸；连击越多，倍率越高（⚠ **按「连击次数」不按「手速」**：每秒最多记 6 拳）。一个「收手」按钮：**按下即结算**（把本局伤害存进总账）。 |
| 规则 | 你的火（HP）**只减不增**；倍率随连击上升（**cap**，见数字）。火尽 = 本局**未入账**的伤害清零（已入账的保留）。 |
| 计分 | 分数 = 本局打出的伤害；「收手」→ 入**总账**；「火尽」→ 本局未入账清零。⚠ **总账与最高分是两个记录**（原稿「进总账 / 只留最高分」混着说了）：**本局分**入**总账**（可接着玩），**最高分**只在 §五 的记录政策拍板后才写。 |
| 结束 | 火尽；或你收手之后重开。 |
| 画面 | 黑红色调（他页面 `--bg-abyss:#0c0503` / `--ember:#ff6b35` / `--crimson:#ff3b30`）+ 他页面上已有的那条**怒气条**语义：**自己的火涨 = 离崩落近**（与页面同向，可以真用 `#rageHud` 的观感）。屏幕边缘随火势泛红、抖动幅度加大（**减动偏好下不抖，只变色**）。 |
| 为什么不是别的 | 全站没有**「风险取舍」**类玩法（push your luck）：不是等时机、不是记忆、不是接 —— 而是**你自己决定什么时候停**。与凯文的差别见 §〇 的「手感家族」。 |
| 验收点 | 四条通用断言 + 量 HUD：连击时倍率上升、火只减不增、收手后分数入账、火尽后归零；**另量**：开局头 3 拳不烧火、收手键离画布 ≥ 100px 且开局 150ms 内忽略。 |
| 风险 | 抖动会碰 WCAG 2.3.1（他页面上已经有一处全屏抖动演出）⇒ **本游戏默认不抖**，只在火势超过 80% 时轻微位移，且减动下完全关掉。**另**：「收手」是**契约第 14 条**管的新键 —— 连点时手指落偏就提前入账（毁掉一次决定），位置与保护期都要照第 14 条量。 |

**数字与教学**（push-your-luck 的全部乐趣就是这条曲线，数字不写死就无从调起）：

- **数字**：火 **100** 起；每拳 **−3.5 火**；伤害 `10 × (1 + 0.15 × 连击)`，连击计数 **cap 8**（倍率上限 ≈ 2.2×）；每秒最多记 **6** 拳。
- **教学**：**开局头 3 拳不烧火**（「试试出拳」）—— 既让人先看懂两条火条的方向，也让人敢一直点下去。
- **目标手感**：第一次玩的人**在剩 60~70% 火时收手**；越熟练越往后推。这条只能真机调，但先按上面这组实现。
- **结束语**（照第 11 条，两句都要是人物语气）：
  · 收手：「你替他决定了什么时候收手。　　留下 **N** 点伤害。」
  · 火尽：「这一次，他烧到了最后一刻。　　留下 **N** 点伤害。」

## 四、不做的事（边界）

- **不写「只有皮」的玩法** —— 判据在前面，先答「这一句是什么」再动手；
- **不复用已有八个玩法的机制**（等时机 / 守 / 躲 / 涂 / 打桩 / 接 / 记顺序 / 烧自己的年岁）；
- **不加音效（决定不变，但理由要改正）** —— 原稿写「本站至今没有一处自动播放声音，加一个就会成为唯一」：
  前半句对（**确实没有自动播放**），后半句**不成立** —— **用户手势触发的 Web Audio 站上已经有先例**：
  伊甸自己的「她的歌」模块（三个振荡器合成和弦、**零音频文件**）与苏那一页的木鱼都是。
  保留这条界线的**真实理由**：**四款要齐**（阿波尼亚 / 维尔薇 / 千劫 三款没有自然的声音，只有伊甸有），
  而且这是致敬站、不是游戏站。
  ⚠ 伊甸那一款要不要破例（两线合成光带的那一下，用她页面上同款的振荡器）⇒ **§五 待拍板**；
- **不做排行榜 / 分享**（那是另一个量级的活，且要 worker 支持）；
- **不为难度牺牲可玩性**：手机上（320 宽）玩不起来就重调，不「先上再看」——
  ⚠ 现在是**有数字**的重调（各款「数字与教学」），不是凭感觉重调。
