## 一、为什么是「按位切」而不是「9 页一起铺」

上一轮的计划写的是「其余 9 页铺开新模块 + 其余 12 位的小游戏」。真动手时发现
**那不是一个 spec 装得下的东西**：

| | 规模 | 卡在哪 |
|---|---|---|
| 铺开探索系统 | 9 页 × 约 12 个可发现物 | 台词必须有出处，而当时以为「6 页没有材料包」 |
| 12 个小游戏 | 12 个**各不相同的玩法** | 玩法一次想 12 个必然互相抄 |

改成**按「位」切**：一次做一位英桀的完整一页（接线 + 她的可发现物 + 她的小游戏）。
好处：

- 每页是**一个自包含的交付物**——做完就是「又一位逛得起来」，而不是「9 页都差一点」
- 素材是**逐位**的，哪位有素材就先做哪位
- 每个游戏是**独立设计**，本来就该一个一个想
- 配方在**真实的一页**上打磨，而不是先抽象再套用

> ⚠ 「台词从哪儿来」这个问题**本轮开始时已经解决**（见 §四）——
> 原以为卡死，实测发现材料包只是**样本**，官方档案馆里还有更多。

## 三、修「鞘中刀」的三处问题

需求方 2026-10-01 原话：「**鞘中刀有个 bug，触发成功一次之后就不会恢复了**」。

复现与根因（已实测）：

```js
function tryDraw(){
  if (gifted){ showToast('……嗯。花还开着。', false); return; }   // ← 到此为止
  …
}
```

`gifted` 持久在 `localStorage['sakuraFlower']`。拿到花之后 `gifted` **永久为真**，
于是这一整块**永远只弹同一句 toast**，再点什么都不会发生。

### 3.1 需求方选定的行为

> **花留着，刀恢复可点。**
>
> 这个名字本身（**勿忘我**）就意味着花**不该忘**——所以花永久保留；
> 但一柄「不肯出鞘的刀」本来就该**永远不驯**，不该在被送花那天之后变成摆设。

```
第一次访问：点1「拒绝」→ 点2「沉默」→ 点3 送花 ✓
之后每次：  点它照样有完整反馈（鞘鸣 + 拒动 + 浮出「纹丝不动」+ 花瓣迸发）
            台词依旧是「拒绝」那句（有出处），只是**不再送花**
```

实现要点：**把 `gifted` 的语义收窄成「还会不会再送花」，而不是「刀还能不能点」。**

### 3.2 连带必须改的提示文案

现在拿到花后提示行写的是：

> 「刀还在鞘里。**你没有再伸手**——这样很好。」

**刀重新可点的那一刻，这句自己就变成假话了。** 必须改。
提示行是**站点 UI 文案**（不是台词），可以动——但要说清改成了什么。

### 3.3 同一次访问里，结尾那句要**当场**出现

结尾的跨彩蛋解锁（收过花 → 结尾多一句 + 多开一朵花）**只在页面加载时判一次**。
所以「收下花 → 往下滚到结尾」当场看不到，**要刷新才有**。

而 HANDOVER §10.3 把这功能描述成「收过花才多一句」，读起来像当场就能看到。**它该当场出现。**

实现：把那一段抽成一个函数，加载时调一次、**收花的瞬间再调一次**。

### 3.4 `sakuraTries` 是死代码

`localStorage.setItem('sakuraTries', …)` **只写不读**——页面上是 `var tries = 0`，
每次访问从零开始。存了个永远没人看的值。

**删掉那行写入。** 新设计下「三次」只在**没拿到花时**才有意义；
拿到之后不该再跨访问累计。

> ⚠ 三处都要**单独 commit 并在正文里标明**：这是修 bug，不是纯重构。

## 四、台词来源（本轮的方法，也是后面每一页的方法）

### 4.1 结论：材料包是**样本**，不是全部

`materials/樱/text_materials.md` 里的 19 条**都是真的**，但它是按需求下限摘的
（材料包自己写着「日常展示 14 条**已超 ≥10 的下限**」）。

**官方档案馆那一页**（材料包标的同一个一手来源：
`https://baike.mihoyo.com/bh3/wiki/content/881/detail`）实测有：

| 状态 | 樱的台词条数 |
|---|---|
| 直接渲染页面 | **51** |
| **点开 39 个折叠段落之后** | **355**（分布在 **35 个子事件**里） |

⚠ 页面上大部分段落是**折叠**的（`[展开]`），**折叠段落里的台词在 `innerText` 里根本不存在**。
不展开就摘，会漏掉 85%。

### 4.2 取材方法（四步）

1. **渲染**页面 —— 它是 SPA，直接 `curl` 只拿得到 6.6 KB 的壳
2. **点开所有 `[展开]`**（实测 39 个）
3. 按小标题切段 —— 小标题形如 `落樱的追忆 · 其三` / `关于毒蛹 · 其一`
4. 收「`樱：`」开头的行，**连同它所在的子事件**

### 4.3 两条纪律

- ⚠ **原文照录，一个字不改。** 页面里用的是 `······`（六个中点）而材料包用 `……`
  —— **不许「规范化」**。改标点也是改台词。
- ⚠ **`src` 必须跟着抄准**：形如 `官方档案馆 · 事件-樱 · 落樱的追忆·其三`。
  出处标错比不标更糟。

### 4.4 两个取舍

- **避开页面上已经展示的**：她语录区那 10 条 + 彩蛋用掉的 2 条，可发现物**不要再用**。
  （上一轮 mobius 12 条里只撞了 1 条——项目基本是避开的。现在有 355 条，避开完全做得到。）
- **`给予刻印` 那批这次不用**：它们是「她给出刻印时说的话」，语境和事件对话不同，
  混进可发现物里会显得断章。留给以后。

## 六、小游戏：「一瞬」

### 6.1 为什么是这个

「**刹那**」是她的刻印；「刀」是她的母题。而**时机**正好能把这两件事变成玩法：
她一生只做一件事——**在那一下出刀**。

和 mobius 的贪吃蛇（「一直活着」）在类型上完全不同：这个是「**只有那一下**」。

### 6.2 玩法

- 屏幕正中一条**斩线**（竖的）
- 目标从一侧向斩线移动
- **点一下（手机点屏幕 / 电脑按空格或点）＝ 出刀**
- 判定按「目标离斩线多远」分三档：

| 判定 | 条件 | 表现 |
|---|---|---|
| **刹那** | 在判定窗内 | 连击 +1，刀光 + 花瓣 |
| 太早了 | 还没到 | 空挥 |
| 晚了 | 已经过去 | 空挥 |

- 一局 **30 秒**
- 计分：正中次数 + 最高连击
- 目标速度**随连击加快**（要有难度曲线，否则 30 秒会无聊）
- 最高分存 `localStorage`

### 6.3 硬约束（照 mobius 那次的规矩）

- **契约照 spec §4.5**：`ElysiaGames.sakura = { title, hint, mount(host) }`
- **不放台词**：结算面板的文字是**站点 UI 文案**，不是她说的台词。
  要放台词只能从档案馆取（有出处）——本 spec 先**不放**，除非到时找到一句特别贴的
- **与探索度解耦**：游戏进度不计入探索度
- ⚠ **减动偏好下游戏内部动画要保留** —— 它由「开始」显式触发，不属「自动播放的装饰动效」
  （上一轮 Review Focus #5，有专门断言）
- 站点面向**大陆手机**：别用老内核不认的 CSS/JS

## 八、她原有的 3 个彩蛋怎么处置

**原则：只在「与别的页雷同」时才改。**（需求方 2026-10-01 定）

| 彩蛋 | 机制 | 全站用过几页 | 处置 |
|---|---|---|---|
| 点刀三次 → 拒绝出鞘、改赠「勿忘我」 | 点专属元素 | 2（kalpas 的面具裂纹 + 她） | **保留** —— 两页不算雷同，且这是她的招牌 |

> 而「点刀三次」也在那儿。**要保证两件事不打架**：
> 可发现物是 44×44 的小热区，刀是整块舞台 —— 点刀时不该误触可发现物，

### 9.1 最大优势：**其余 10 页完全不动**

| 检查 | 期望 |
|---|---|
| `snapshot_diff after-bday after-sakura` | **`/sakura/` 之外零差异**；sakura 的差异**逐条可解释**（新增的可发现物 + 下方区块 + 刀的状态变化） |

| `check_reduced_motion.py` | **7 / 7** |
| `check_explore.py sakura/index.html` | 全绿 |
| `check_explore.py`（探针页） | 全绿 —— **别弄坏探针页** |

⚠ 参照点是 **`after-bday`**（`screenshots/snap/` 里现在只有 `baseline` 与 `after-bday`）。
⚠ **快照跑完再跑差分**，判据是「输出末尾有『快照存入』且进程真的退出」——
**重跑同一 label 时文件数判据会骗你**（HANDOVER §6.4）。

### 9.2 要专门验的（快照测不到的）

1. **鞘中刀的三处修复**：
   - 拿到花之后再点，**仍有完整反馈**（鞘鸣 / 拒动 / 浮字 / 花瓣），且**不再送花**
   - 收花的**同一瞬间**，结尾那句和那朵花**当场出现**（不用刷新）
   - `sakuraTries` 不再被写入
2. **可发现物 × 刀舞台不打架**（§八的 ⚠）
3. **「一瞬」**：开始后目标真的在动；减动下**仍然在动**
4. **台词全部有出处**：页面上出现的每一句引号内台词，都能在抓下来的档案文本里逐字找到
   （⚠ 包括 `······` 这种写法**逐字相同**）
5. **她把 12 个可发现物与语录区零重复**
