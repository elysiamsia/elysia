## 现状诊断（已实证）

用无头 Edge（CDP）实际打开 `index.html` 验证，确认了语录 bug：

- **根因**：`index.html:472` 点击处理里写 `grid.querySelectorAll('.quote-card').indexOf(card)`。
  `querySelectorAll()` 返回的是 **NodeList**，NodeList 只有 `forEach/length`，**没有 `indexOf` 方法**。
- **实测输出**：`typeof NodeList.indexOf = undefined`；调用时抛 `EXCEPTION: ...indexOf is not a function`。
- **后果**：每次点击就抛 `TypeError`，语录文字永不切换——这就是「点击后没有反应」。
- 已确认**无元素遮挡**（`elementFromPoint` 返回卡片本身），非叠加层问题。

**配音素材**：目录已有 8 段 `.wma` 真人配音，逐一一对应前 8 条语录：
`01_嗨想我了吗 / 02_此后将有群星闪耀 / 03_请将我的剑我的花 / 04_悲剧并非终结 / 05_美丽的女孩子什么都能做到 / 06_如你所见与那个凯文齐名 / 07_而你将走向未来 / 08_愿你前行的道路有群星闪耀`。

**转换工具已验证**：系统无 ffmpeg，但 `.venv` 的 `imageio-ffmpeg`（内置静态 ffmpeg v7.1）可正常转码。实测 `01_嗨想我了吗.wma` → `.mp3`（128k，39KB）成功。文件名含中文，需注意编码。

**数据源已验证**：境外 `honkai.fandom.com` 当前网络连不通（000），但 **B 站崩坏3 wiki `wiki.biligame.com/bh3/爱莉希雅` 可访问（200）**，并已找到「真我·人之律者」装甲子页链接。米游社 `miyoushe.com/bh3` 也通。时间轴数据以这两个中文源为准逐条核对，不编造。

## 需求一：修复语录 bug + 接入真人配音

### 修复方式
不再每次点击都用 `indexOf` 扫描 NodeList。**在创建卡片时用闭包固化索引**：

```js
quotes.forEach(function(q, i) {
  const card = {...};
  const textEl = ...;
  let cur = i;                                  // 闭包固化，O(1)，不查 DOM
  card.addEventListener('click', function() {
    const next = (cur + 1) % quotes.length;
    // 1. 淡出文字
    textEl.classList.add('fading');
    // 2. 切音频：打断正在播的，播下一条
    const audio = audioFor(cur+1);              // 1~8 有配音，9、10 静音
    playQuoteAudio(audio, textEl);              // 淡出期间播
    setTimeout(function() {
      textEl.textContent = quotes[next];
      cur = next;                               // 更新闭包索引
      textEl.classList.remove('fading');
    }, 400);
  });
});
```

### 配音接入
- 8 段 `.wma` 用 `imageio-ffmpeg` 批量转成 `.mp3`，**文件名保留原名**（如 `01_嗨想我了吗.wma` → `audio/01_嗨想我了吗.mp3`），放 `audio/` 目录。mp3 命名以转码脚本实际输出为准，映射关系在数据文件中显式列出。
- 每条语录卡片点击时：淡出文字 → 切下一句 → `new Audio('audio/<对应文件名>.mp3').play()`。
- **防叠音**：每次点击先 `audio.pause(); audio.currentTime = 0;` 打断上一条再播新的；连续快速点击不会叠声。
- **配音映射**（1 基计数，与用户名一一对应）：
  - `01_嗨想我了吗 / 02_此后将有群星闪耀 / 03_请将我的剑我的花 / 04_悲剧并非终结 / 05_美丽的女孩子什么都能做到 / 06_如你所见与那个凯文齐名 / 07_而你将走向未来 / 08_愿你前行的道路有群星闪耀` → 点击播放对应 mp3。
  - 第 9、10 条语录（无配音素材）→ 静音切换，仅换字。
- 引用关系在数据文件里**显式写出文件名**，不靠位次猜。

## 需求二：装甲三轴时间轴

### 数据模型（共享单源 `data/timeline-data.js`）
每条记录一个对象：
```js
{
  id: 'armor-01',
  type: 'armor' | 'skin' | 'story' | 'event',   // 四类
  title: '「真我」·人之律者',
  subtitle: 'S级装甲',
  real_date: '2023-01-13',                      // 现实上线的日期
  version: 'v6.0',                              // 游戏版本实装
  ingame_time: '前文明纪元 · 往世乐土',          // 游戏内时间（剧情/章节）
  desc: '一句话简介。',
  detail: '展开面板的详细描述（可选）。',
  audio: 'audio/xx.mp3 | null'                  // 可选配音（事件类往往无）
}
```
- **主页面**引同一份源，只 `filter` 出精选（6~8 条核心里程碑）。
- **独立页** `armor.html` 同一份数据，全量渲染 + 筛选器。
- **单一数据源**保证两页一致，改一处同步更新。

### 主页面精简版（`index.html` 新增 section）
- 位置：`她的旅途`（剧情）之后、`飞花寄语` 之前。
- 标题：「她的装甲 · 她的芳华」，沿用现有飞花标题样式（`section-title` + `section-title-petal`）。
- 复用现有 `.timeline` 竖向节点样式但**单列**（不做左右交错，精简版更清楚）。
- 每条显示：类型徽标（四色）+ 现实日期 + 版本 + 一句话。
- 底部「查看完整时间轴 →」链接跳 `armor.html`。

### 独立完整页（`armor.html`）
- 完整复用主页面气质（粉紫玻璃拟态、樱瓣 canvas、星尘背景），标题可稍大。
- **顶栏筛选器**：
  - 四类多选筛选（装甲 / 皮肤 / 剧情 / 活动）
  - 「按现实日期排序」开关
  - 「清空筛选」按钮
- **三轴对照**：每条显示现实的日期 / 游戏版本 / 游戏内时间三行信息。
- **竖向滚动时间轴**：按现实日期排列，左右交错卡片（复用主图交错样式），节点圆点 + 连接线。
- **点击卡片展开**折叠小面板，显示详细描述。
- 顶部「← 返回 elysiad.top」链接回首页。
