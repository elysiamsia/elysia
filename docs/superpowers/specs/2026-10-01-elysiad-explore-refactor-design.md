# 公共层重构：探索系统 + 下方区块（游戏 / 生日倒计时）

> **本轮的定位**：把站点的公共层从「管样式的」升级成「管体验的」——
> 让每个英桀页从「可以看」变成「可以逛」。
>
> 起草日期：**2026-10-01**
> 范围：**公共层重构 + `/mobius/` 一页打通 → 上线**。其余 9 页下一轮铺。
> 前置：`docs/HANDOVER.md`（本文档里 §x.y 的引用都指它）

---

## 一、为什么要做

需求方原话：

> 「英桀的彩蛋有些雷同，没有新意。我要的彩蛋是**用户随意在页面点击都可以触发**的，
> 要让用户觉得**页面一直有探索的空间**。」

盘点现状后确认问题出在哪：

| 现状 | 问题 |
|---|---|
| 彩蛋机制就那十几种（点名字 / 双击 / 闲置 / 连点…），13 页轮着用 | 玩到第 3 页就腻了 |
| 一页只有 3 个彩蛋，触发完就没了 | **没有「还剩多少」的感觉**，探索度为零 |
| 全部彩蛋都是「点某个特定元素」 | 点页面其他地方**什么都不会发生** |

**这一轮要解决的，是「探索感」本身，不是再加几个彩蛋。**

### 1.1 需求方选定的方向（2026-10-01 问答）

问到「探索感靠什么维持」时，选中的是这三条，**明确没选「不可预测 / 抽卡」**：

| 要 | 不要 |
|---|---|
| ✅ 隐藏内容——真的有东西藏着，要找 | ❌ 抽卡式不可预测 |
| ✅ 收集与解锁——有一个在慢慢填满的清单 | |
| ✅ 陪伴感——每次点击都有一点回应 | |
| ✅ 页面添加更多可交互功能 | |

> ⚠ **这一条是全局约束**：表层反应要**稳定、可预期**，不做概率抽奖。
> 惊喜全部来自「找到了藏起来的东西」，不来自「运气」。

## 四、契约

### 4.1 `THEME` 新增字段

沿用 `docs/theme-schema.md` §一的铁律：
**`THEME` 只装「这一页是谁」的东西；逐页相同的留共享层当默认值。**

```js
var THEME = {
  endingStars: { … },   // 现有
  quotes:      { … },   // 现有
  typewriter:  { … },   // 现有

  /* ── 新增 ─────────────────────────────────────────── */
  explore: {
    finds: [
      {
        id:   'lab-01',        // 页内唯一，存进度用。改名 = 玩家进度丢失
        at:   '#about',        // 锚点选择器（页面上**必须已存在**；找不到就 warn 跳过，不抛）
        x:    0.18, y: 0.62,   // 相对锚点元素矩形的百分比 [0..1]
        verb: 'hold',          // click | hold | drag | triple_tap | slide
        art:  'spore',         // 外观关键字（见 §5.2）
        line: '「…」',          // 台词——**必须有出处**，见 §六
        src:  '蛇主的追忆·其一', // 出处标注，渲染在气泡角落
      },
      /* …共 8~12 个 */
    ],
    unlock:  { title: '…', text: '「…」', src: '…' },  // 找齐后展开
    whisper: ['「…」', '「…」'],                        // 陪伴层台词池
    whisperCooldownMs: 8000,                            // 可选，默认 8000
    hintAfterRatio: 0.5,                                // 可选，找到过半才开始给提示
  },

  game: { module: 'mobius', title: '…', hint: '…' },
};
```

> ⚠ **`THEME` 里没有 `bday`** —— 生日数据只有一处，见 §4.4。

### 4.2 `ElysiaExplore`（`assets/explore.js`）

```js
ElysiaExplore.init(THEME.explore);
```

| 职责 | 说明 |
|---|---|
| 生成可发现物 | 按 `finds` 在锚点内定位，注入 DOM |
| 互动 | 5 种动词，命中后播放该 find 的表现 + 台词气泡 |
| 进度 | 记录已发现集合，渲染 `✦ 3 / 12` |
| 渐进提示 | 找到 ≥ `hintAfterRatio` 后，未找到的**轻微闪一下**（不动位置，避免误触） |
| 解锁 | 找齐 → 展开 `unlock`（**只出现这一次**） |
| 陪伴层 | 任意点击 → 现有涟漪 + 节流后的低语 |
| 存储 | `localStorage['elysia:explore:<页>']`，`try/catch`，失败降级内存 |

### 4.3 `ElysiaBottom`（`assets/bottom.js`）

```js
ElysiaBottom.mount({ game: THEME.game });
```

**两个槽，各自独立**：

| 槽 | 出现条件 | 内容 |
|---|---|---|
| **游戏槽** | `THEME.game` 存在 | 一张游戏卡（标题 + 一句话 + 「开始」按钮）→ 由 `games/<角色>.js` 自己渲染 |
| **倒计时槽** | `data/bdays.js` 里有这一页的条目 | 生日倒计时 |
| **探索度** | 恒有 | `✦ 3 / 12` + 解锁区 |

### 4.4 `data/bdays.js` —— **全站唯一数据源**

```js
/* 只有「有确定生日」的英桀才写在这里。查不到 / 待考的，整条不写。 */
window.ELYSIA_BDAYS = {
  'index.html':   [10, 11],   // 爱莉希雅 11/11
  'sakura/index.html': [6, 22],   // 樱 7/22（需求方 2026-09-17 确认）
  'mobius/index.html': [3, 30],   // 梅比乌斯 4/30（材料包）
  'hua/index.html':    [1, 9],    // 华 2/9（材料包）
  'griseo/index.html': [11, 21],  // 格蕾修 12/21（材料包）
  'pardofelis/index.html': [6, 11], // 帕朵菲莉丝 7/11（材料包；需求方 2026-10-01 认可）
};
```

- **纯数据模块**：不含 DOM 操作、不含格式化逻辑
- `ElysiaBottom` 按 `location.pathname` 查表；**查不到就不渲染倒计时槽**
- 月份**从 0 起**（与页面里 `var BM = 3, BD = 30` 的既有写法一致）
- 可以**先把还没建的页也写上**（上表的 `hua/` `griseo/` 就是）—— 页建好之后自动生效，不用回头改
- ⚠ 这与 **HANDOVER §10.5** 合并 `BUILT` 开关是同一条教训：**同一件事两处维护，迟早漏一处**
- ⚠ 其余 8 位英桀的生日**本轮未查**。查不到就不写进表里——按项目纪律，**不猜**

### 4.5 `games/<角色>.js` 契约

```js
window.ElysiaGames = window.ElysiaGames || {};
window.ElysiaGames.mobius = {
  title: '…',
  hint:  '…',
  mount: function (host) { /* 自己渲染进 host，自给自足 */ },
};
```

- 只有 `mount(host)` 一个必需方法，**不强制生命周期钩子**（当前规模不需要，避免过早抽象）
- 若日后需要清理，在 `bottom.js` 里约定「替换前调用旧实例的 `destroy?.()`」作为**可选**扩展点
- ⚠ 游戏**不参与**探索度计数——两个系统互不牵扯，各自干净

## 五、探索系统行为规格

### 5.1 五种互动动词

命名统一为**全小写 + 下划线**：

| `verb` | 用户动作 | 判定 |
|---|---|---|
| `click` | 点一下 | 单击 |
| `hold` | 长按 | 按住 ≥ 600ms |
| `triple_tap` | 连点 3 次 | 1.2 秒内 3 次 |
| `drag` | 拖 | 按下后位移 ≥ 24px |
| `slide` | 划过 | 指针经过且速度快于阈值（**不做悬停**——手机上不存在） |

> 移动端优先：所有可发现物的触控热区 **≥ 44×44 px**。

### 5.2 外观关键字（`art`）

由 `explore.js` 提供一组**通用简笔画**（canvas 或内联 SVG），`art` 选一个。
每位英桀可以通过 `explore.css` 里的 CSS 变量改色，不需要新代码。

初始提供：`spore` / `scale` / `glint` / `record` / `shadow` / `throne` / `shed` / `infinity` / `mouse` / `sleeping` / `silhouette` / `brick`

### 5.3 陪伴层（表层的「每次点击都有一点回应」）

⚠ **这是全局约束的落点：不做抽卡。**

规则（**稳定、可预期**）：

1. 点击非交互元素 → 现有涟漪照旧
2. 涟漪之上，**节流**：`whisperCooldownMs`（默认 8000）内的点击不触发低语
3. 冷却结束后的**第 3 次**点击说一句 —— **次数固定，不随机**
4. 台词**按顺序推进**（不随机抽），循环
5. 低语是一个轻气泡，2.5 秒后自己消失，不挡内容

> 为什么「第 3 次」而不是概率：需求方明确不要不可预测。
> 可预期的陪伴才像「有人在那里」；概率会让它变成抽奖。

### 5.4 存储

```js
localStorage['elysia:explore:mobius']
  → { "found": ["lab-01","lab-04"], "unlocked": false }
```

- 全部读写包在 `try/catch` 里（隐私模式 / Safari ITP 会抛）
- 失败 → **静默降级为内存对象**，不提示、不改行为，只是刷新后从头开始
- ⚠ 换设备会丢进度。**这是有意接受的取舍**（不做账号体系）

### 5.5 减动（WCAG 2.3.1）

| 项 | 正常态 | 减动态 |
|---|---|---|
| 可发现物的漂浮 / 呼吸 | 有 | **静止** |
| 渐进提示的闪烁 | 闪 | 改为**常亮的淡边框**，不闪 |
| 低语的粒子 | 有 | 只出文字 |
| 台词气泡的展开 | 位移淡入 | 直接显示 |
| 小游戏**内部**的动画 | 保留 | **保留**（游戏就是要玩的；它由「开始」按钮显式触发，不属「自动播放的装饰动效」） |

⚠ 最后一条要在 `check_reduced_motion` 里有**明确断言**，别让它变成「测了等于没测」。

### 5.6 无障碍

| 元素 | 要求 |
|---|---|
| 每个可发现物 | `role="button"` `tabindex="0"` + `aria-label`（**共享默认值**，不进 THEME） |
| 键盘可达 | 12 个 find 都是 tab stop，Enter / Space 触发 |
| 探索度 | `role="status"` `aria-live="polite"`，文案 `已发现 3 / 12` |
| 解锁区 | 展开时 `aria-live="polite"` |

## 八、mobius 原有 6 个彩蛋的处置

需求方说彩蛋「有些雷同」。逐条对过既有机制后：

| 彩蛋 | 原机制 | 处置 |
|---|---|---|
| A 蛇瞳凝视 →「登神之刻」 | 连点专属元素 4 次 | **保留** —— 专属元素 + 机制少见 |
| **B 点名字** | 点名字出 toast | ⚠ **不删，改机制** —— 见 §8.1 |
| C 标题吐槽 | 点章节标题 | **保留** —— 全站唯一（`data-snark` 只有这页有） |
| **D 结尾点语录循环** | 点结尾句换句 | ⚠ **不删，改机制** —— 见 §8.2 |
| E 小白鼠出没 | 随机冒出会跑的可点小生物 | **保留** —— 与可发现物同类但「会跑」，有区分度 |
| F 贪吃蛇 | 小游戏 | **搬进游戏槽**（§6.3） |

> **需求方 2026-10-01 的决定**：B / D **不删，但把机制改掉**
> —— 它们的问题不是内容，是**触发方式**：
> 「点名字」已有 kalpas / su / villv 三家用过，「点结尾语录循环」也有 kalpas / su / villv 三家用过。

### 8.1 B 改法：**拖走她的名字**

| | |
|---|---|
| **新机制** | **拖拽**（drag） —— 把「梅比乌斯」这个名字从档案卡上拖走 |
| **表现** | 名字跟手走，卡片上留一个空位；松手后名字**像蛇一样自己游回原位** |
| **为什么是她** | 这一页的核心真相就是「名字 ≠ 存在」（解锁句：「从一开始这里就不存在什么「梅比乌斯」的记忆体」）。**把名字拖走**，正好把这件事演了一遍 |
| **为什么不算雷同** | 全站**没有任何一页用过拖拽**。既有的 15 种机制（见 HANDOVER §4.2）里没有它 |
| **台词** | 「你要是有什么想评判的，就等你知道了真相之后再说吧。不过在那之前别忘了，这条供你探寻的路，可是我为你铺起来的。」 —— 关于黄金庭园·其一 |
| ⚠ | 与可发现物 `lab-07`（拖动王座）**同为 drag**。对象不同，可接受；但若觉得重复，可把 `lab-07` 换成 `click` |

### 8.2 D 改法：**在结尾往回滚**

| | |
|---|---|
| **新机制** | **反向滚动** —— 走到结尾之后，**向上滚回上一节**时触发 |
| **表现** | 结尾那句下面再浮出一行，是她的临别提问 |
| **为什么是她** | 结尾本来就在说「别走」；**你往回滚 = 你要走了**，她才开口。这一句是送别 |
| **为什么不算雷同** | 既有的「滚动到结尾触发」（aponia / eden / kevin）是**往下滚到**结尾；这个是**从结尾往回滚**，方向相反，且那三页是「到达即触发」，这个是「离开才触发」 |
| **台词** | 「人类称呼自己能够理解的答案为「真相」，却称那无法理解的为「谬论」，说那人是「疯子」。至于你，你到最后会怎么看这一切？我可是很期待的哟，律·者·姐·姐。」 —— 关于千劫·其二 |
| ⚠ | 桌面与手机都能触发（都是滚动），不像 `mouseleave` 那样手机没有 |

> ⚠ **这两条台词是从 §6.5「余量」里取的**，所以它们**不再算余量**。
> 剩下 5 条仍然空着。（余量表已同步更新。）

**处置结果**：mobius = **3 个专属彩蛋（A / B' / C / E —— 其中 B 换了机制）+ 12 个可发现物 + 1 个小游戏 + 倒计时**。
